# Manuscript: Precession as a hidden field

- `main.tex` — REVTeX 4.2 (aps, prb, twocolumn). Compile with `pdflatex main.tex` twice (Overleaf or any TeX Live with revtex4-2).
- `figs/` — 10 vector figures (PDF), produced by `figsrc/*.py` (matplotlib; data paths point to the project repository results).
- `preview_article_layout.pdf` — preview compiled with the standard `article` class because REVTeX was not available in the build environment; page layout and float positions will differ slightly from the REVTeX build.
