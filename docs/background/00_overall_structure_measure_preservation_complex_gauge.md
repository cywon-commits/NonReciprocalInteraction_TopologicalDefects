# 비상반 스핀 결합: 측도 보존, 유효 에너지, 복소 게이지 (논문 구조안)

Oct 4, 2026 · Changyeon Won (Kyung Hee University)

## 제목 후보와 초록

핵심 주장: 스핀 결합의 비상반성은 스핀류 하나로 매개되며, 그것이 평형을 보존하는지, 흉내 내는지, 깨는지는 SO(3) 대칭 분해와 작용 채널(세차/감쇠)만으로 결정된다.

**제목 후보**

1. 비상반 스핀 결합: 볼츠만 측도 보존의 분류와 전류 유도 유사 에너지
2. Nonreciprocal spin couplings: Gibbs-preserving classes, pseudo-energies, and a single invariant behind current-induced DMI and Walker breakdown
3. Complex gauge fields for magnons: the Dzyaloshinskii–Moriya interaction as the Hermitian partner of nonreciprocal exchange

**초록 초안**

스핀 동역학의 유효장은 보통 에너지에서 유도되어 결합이 상반적이다. 우리는 결합 행렬이 전치 대칭을 깨는 비상반 결합을 스핀류가 흐르는 열린 계의 유효 기술로 정식화한다. 비상반 결합의 발산은 구면 위에서 자동으로 0이므로, 볼츠만 분포 보존은 비상반 흐름의 점별 에너지 보존과 동치이다. 이 조건으로 쌍선형 결합을 대칭 차수와 채널에 따라 분류하고, 정확한 해가 시간 척도 재정의, 1차원 이산 이류, 토크 결합의 세 종류뿐임을 보인다. 깨지는 경우의 정상분포는 동역학 계수 α에 의존하는 유사 에너지로 기술된다. 선형 영역에서는 유효 DMI로, 고온에서는 스칼라 키랄성 장으로 나타나며, 둘 다 u\_eff = (β−α)u/α 하나로 정해진다. 같은 불변량이 Walker breakdown 문턱을 결정하고, 유한 온도에서는 벽 각도의 확률류를 만든다. 마지막으로 DMI와 비상반 교환이 마그논 복소 게이지장의 실수부와 허수부임을 보이고, 전류–DMI 보상점이 두 개로 갈라지는 현상에서 비단열 계수 β를 측정하는 방법을 제안한다. 모든 해석적 예측은 확률 LLG 계산으로 맞춤 매개변수 없이 확인된다.

## 1. 서론

서론의 논지는 "비상반 결합은 이미 스핀트로닉스에 숨어 있으며, 그것을 결합의 언어로 쓰면 평형과의 관계가 대칭만으로 분류된다"이다.

**동기.** 스핀 해밀토니안에서 유효장을 구하면 i가 j에 주는 결합과 j가 i에 주는 결합이 같다. 그런데 Slonczewski, Zhang–Li, 스핀–궤도 토크는 모두 에너지에서 유도되지 않는 항이다. 능동 물질과 비상반 상전이 연구(Fruchart 등, 2021)는 비대칭 결합이 새로운 상을 만든다는 것을 보였다. 두 흐름을 잇는 질문은 "스핀 결합의 비대칭이 언제 평형과 양립하는가"이다.

**질문.**

1. 어떤 비상반 결합이 볼츠만 분포를 정확히 보존하는가?
2. 깨지는 경우 정상분포는 어떤 유효 에너지로 기술되며, 그 에너지는 국소적이고 동역학 계수와 무관한가?
3. 그 유효 에너지는 도메인벽 동역학과 정적 DMI와 어떻게 이어지는가?

**기여.**

1. 비상반 결합을 SO(3) 기약 표현(차수 0, 1, 2)과 교환 홀짝성으로 분해하고, 스핀류 J\_s와의 대응식을 세운다.
2. 비상반 흐름의 발산이 자동 소거됨을 보이고, 측도 보존의 완전한 쌍선형 분류와 격자 무관 토크 결합 해를 제시한다.
3. 유효 에너지를 G1(평형 등가), G2(국소 유사 에너지), G3(진짜 비평형)로 판정하는 기준과, G1이 진짜 비상반성에서는 불가능하다는 정리를 준다.
4. FL 채널 비상반성이 유효 DMI와 키랄성 장을 만들며, 계수가 1/α에 비례함을 해석적·수치적으로 보인다.
5. 같은 불변량 u\_eff가 Walker breakdown을 결정함을 보이고, 유한 온도 위상 미끄러짐을 기울어진 빨래판으로 정량 예측한다.
6. DMI와 비상반 교환을 하나의 복소 게이지장으로 통일하고, 두 보상점으로 β를 측정하는 방법을 제안한다.

## 2. 모형

비상반성은 두 채널(세차 FL, 감쇠형 DL)과 세 대칭 차수로 완전히 분해되며, 그 크기는 스핀류 밀도로 주어진다.

**2.1 채널 분해.** 상반 부분은 표준 확률 LLG로 두고 잡음 없는 비상반 드리프트를 더한다. Fokker–Planck 분석은 LL 꼴에서 한다.

```latex
\dot{\mathbf S}_i = \dots - \gamma\,\mathbf S_i\times\mathbf h_i^{N,\mathrm{FL}} - \gamma\,\mathbf S_i\times(\mathbf S_i\times\mathbf h_i^{N,\mathrm{DL}}),\qquad \mathbf h_i^{N}=\sum_{j\neq i}N_{ij}\mathbf S_j
```

Gilbert 꼴 계수에서 LL 채널로의 변환은 다음과 같다. LL의 FL 성분이 (β−α)에 비례한다는 점이 이후 모든 결과의 출발점이다.

```latex
N^{\mathrm{FL}}_{\mathrm{LL}}=\frac{\delta J^{\mathrm{FL}}-\alpha\,\delta J^{\mathrm{DL}}}{1+\alpha^2},\qquad N^{\mathrm{DL}}_{\mathrm{LL}}=\frac{\delta J^{\mathrm{DL}}+\alpha\,\delta J^{\mathrm{FL}}}{1+\alpha^2}
```

**2.2 대칭 분해.** 상반 조건은 A\_ji = A\_ij^T, 비상반 조건은 N\_ji = −N\_ij^T이다. 각 차수마다 교환 홀짝성이 정반대로 뒤집힌다.

| SO(3) 차수 | 상반 | 비상반 |
| --- | --- | --- |
| 0 (스칼라) | J\_ij, 교환에 짝 | δJ\_ij, 교환에 홀 |
| 1 (벡터) | D\_ij, 홀 | n\_ij (같은 방향 회전 δD), 짝 |
| 2 (대칭 무대각합) | Γ\_ij, 짝 | δΓ\_ij, 홀 |

**2.3 물리적 근거.** 정적 유효결합은 자유에너지의 2차 미분이므로 평형에서는 반드시 대칭이다. 비상반성은 상세균형이 깨지고 결합 방향을 구별하는 극성 벡터(흐름)가 있을 때만 생긴다. 흐르는 소산 매개체를 적분하면 다음을 얻는다.

```latex
\delta J(\mathbf r) = -(\mathbf v\cdot\nabla)\,\Gamma(\mathbf r)
```

δJ는 구동에 대해 홀이고, 매개체의 소산 Γ가 없으면 사라진다.

**2.4 스핀류 대응.** 알려진 토크는 모두 다음 하나로 쓰인다.

```latex
\delta J^{\mathrm{DL}}_{ij}=-\tfrac{a^2}{2}\,(\mathbf J_s\cdot\hat e_{ij}),\qquad \delta J^{\mathrm{FL}}_{ij}=\beta\,\delta J^{\mathrm{DL}}_{ij}
```

| 알려진 효과 | 비상반 매개변수 |
| --- | --- |
| Zhang–Li 단열 토크 | δJ^DL, J\_s = Pħj/2e |
| Zhang–Li 비단열 토크 | δJ^FL = β δJ^DL |
| Slonczewski (층간) | 층간 δJ^DL, 단위면적당 J\_s = ηħj/2e |
| 감쇠형 SOT | FL 채널 δD, d̂ ∥ σ ∥ ẑ × j |
| 마그논 STT (∇T) | δJ^DL, J\_s ∝ −ħ j\_m |
| 엔트로피 토크 | 비상반 아님 (J(T(x))의 공간 변화) |

연속 극한에서 위 대응은 Zhang–Li와 Slonczewski 식을 계수까지 재현한다. j = 10^12 A/m², a = 0.3 nm이면 δJ^DL ≈ 0.04 meV, δJ/J ≈ 10^-3이다. 선형 응답 가정 |δJ| ≪ |J|는 실제 구동 크기와 맞는다.

## 3. 볼츠만 측도를 보존하는 비상반 결합의 분류

쌍선형 비상반 결합 중 볼츠만 분포를 정확히 보존하는 것은 시간 척도 재정의, 1차원 이산 이류, 토크 결합의 세 종류뿐이다.

**정리 1 (발산 소거).** 비상반 흐름은 두 채널 모두에서 발산이 0이다. FL 채널은 구면의 Killing 장이고, DL 채널은 l = 1 조화함수의 기울기라서 다음이 성립한다.

```latex
\nabla\cdot\mathbf g^{\mathrm{DL}}=\gamma\sum_{i\neq j}\mathbf S_i^{T}\big(N_{ij}+N_{ji}^{T}\big)\mathbf S_j=0
```

따름정리: 볼츠만 보존은 비상반 흐름의 점별 에너지 보존 dE\_N/dt ≡ 0과 동치이다.

**에너지 변화율.**

```latex
\dot E_{\mathrm{FL}}\propto\sum_i\det\big(\mathbf S_i,\mathbf h_i^{N},\mathbf h_i^{R}\big),\qquad \dot E_{\mathrm{DL}}\propto-\sum_i\mathbf h_i^{R}\cdot P_i\,\mathbf h_i^{N}
```

**정리 2 (FL 채널 δJ).** 등방 교환에서 해는 이분 격자의 엇갈린 비율뿐이며, 이는 부격자별 회전자기비 차이와 같다. 1차원 사슬에서는 dE/dt = 2JδJ Σχ\_i로 스칼라 키랄성 펌프가 된다. 삼각형 계수는 δJ의 회전량이며, 이는 게이지 고리 조건의 선형화이다.

**정리 3 (DL 채널 δJ).** 두 자리 항은 항상 상쇄되고, 세 자리 항의 계수는 r\_k + r\_l = 0을 요구한다(r\_k = δJ\_ik/J\_ik). 배위수 3 이상에서는 해가 없고, 배위수 2에서는 균일한 방향 편향이 정확한 해이다.

**정리 4 (1차원 일반 결합).** N\_{i,i±1} = ±rR\_{i,i±1}이면 dE/dt는 망원급수가 되어, R이 정규행렬일 때 정확히 0이다. J + D는 항상 정규이므로, 상반 DMI의 이류 짝으로서 δD는 측도를 보존한다.

**정리 5 (자리 항).** 제만 항이나 이방성 항은 쌍선형 DL 해의 정확성을 깨지만, 위반은 기울기 전개 O(a³)에서 시작한다. 2차원 x 방향 편향도 O(a²), O(a³) 항이 전미분이라, 연속 극한에서는 순수 이류로 보존된다.

**정리 (토크 결합).** 서로 다른 자리의 Killing 장으로 만든 반대칭 2-벡터는 발산이 0이다. 따라서 다음 결합은 격자와 에너지에 무관하게 볼츠만을 보존한다.

```latex
\mathbf B_i^{N}\propto\sum_j C_{ij}\,\boldsymbol\tau_j,\qquad \boldsymbol\tau_j=\mathbf S_j\times\mathbf h_j^{R},\qquad C_{ji}=-C_{ij}^{T}
```

| 비상반 성분 | FL 채널 | DL 채널 |
| --- | --- | --- |
| δJ (차수 0) | 이분 격자 γ 재정의만, 그 외 키랄성 펌프 | 배위수 2에서 정확, d ≥ 2는 격자 척도에서 위반 |
| δD (차수 1) | 항상 깨짐 (SOT형) | 상반 D의 이류 짝일 때만 보존 |
| δΓ (차수 2) | 항상 깨짐 | 상반 Γ의 이류 짝일 때만 보존 (R 정규) |
| 토크 결합 | 모든 격자, 모든 E에서 정확 | 해당 없음 |

**해석.** 정확한 해는 모두 에너지 대칭의 생성자이다. 각각 자리별 시간 척도, 병진, 푸아송(자이로) 구조에 해당한다. 같은 차수 0·홀 대칭이라도 스핀에 결합하면 2차원에서 깨지고, 토크에 결합하면 항상 보존된다.

## 4. 깨지는 경우의 유효 에너지: G1–G3 판정

깨지는 경우의 정상분포는 형식적으로 항상 e^{−βE'}로 쓸 수 있지만, 진짜 비상반성에서 E'은 반드시 1/α에 의존하는 동역학적 대상이다.

**4.1 판정 기준.** 정확한 조건은 퍼텐셜 조건이다.

```latex
\mathbf f_{\mathrm{total}}=-\Lambda\nabla E'+\Omega'\nabla E'\quad(\Omega'\ \text{발산 없는 반대칭 2-벡터})
```

섭동 1차에서는 세차를 뒤집은 상반 생성자 L†에 대한 방정식이 된다. 평균이 0이므로 해는 항상 있다. 의미 있는 기준은 E'의 국소성과 α 무관성이다.

```latex
L^{\dagger}E_1=\dot E_N,\qquad L^{\dagger}=\Lambda\big(k_BT\,\Delta-\nabla E\cdot\nabla\big)-(\Omega_0\nabla E)\cdot\nabla
```

**정리 A′ (G1 = G0, 비섭동적).** Gilbert 꼴 비상반 장 H = h^R + h^N에서, α와 T에 모두 무관한 E'의 깁스 분포가 정상해일 필요충분조건은 E' = E + const이고 두 채널이 동시에 볼츠만을 보존하는 것(Φ\_D ≡ Φ\_F ≡ 0)이다.

증명은 두 번의 선형 분리로 이루어진다. 첫째, 정상 조건은 α에 대해 선형이므로 세차와 감쇠 조건이 따로 성립해야 한다.

```latex
\text{(I)}\ \nabla\cdot(\pi'\mathbf w)=0,\quad \mathbf w=P\mathbf h^N+\tfrac{1}{\mu}\nabla E_1;\qquad \text{(II)}\ \nabla\cdot(\pi'\,\mathbf S\times\mathbf H)=0
```

둘째, ∇·(π'v) = π'(∇·v − β∇E'·v)는 β에 대해 선형이므로 발산 조건과 에너지 보존 조건이 따로 성립해야 한다. 정리 1에 의해 ∇·(Ph^N) = 0이므로 (I)에서 ΔE\_1 = 0이 나오고, 콤팩트한 (S²)^N 위의 조화함수는 상수뿐이므로 E\_1 = const이다. 그러면 (I)과 (II)는 각각 다음이 된다.

```latex
\Phi_D\equiv\nabla E\cdot P\mathbf h^N=0,\qquad \Phi_F\equiv\nabla E\cdot(\mathbf S\times\mathbf h^N)=0
```

**따름정리 (격자).** 등방 교환 E에서, 서로 이웃이 아닌 두 이웃을 가진 자리에서는 FL 조건이 δJ\_ik/J\_ik = δJ\_il/J\_il을, DL 조건이 δJ\_ik/J\_ik = −δJ\_il/J\_il을 요구한다. 삼각형에서는 DL이 균일 방향 편향을 요구하지만, 그러면 FL 회전량이 6rJ ≠ 0이다. δD와 δΓ는 FL 채널이 두 자리 수준에서 이미 0이 아니며, 다른 SO(3) 성분과 상쇄되지 않는다. 따라서 정점 3개 이상의 연결 격자에서 쌍선형 N ≠ 0이면 G1은 없다. 이합체는 Φ\_D = Φ\_F = 0이라 정확히 G0인 예외이다.

**고정 T (α 무관성만 요구).** 1차 섭동에서 E\_1 = L\_D^{-1}Φ\_D가 유일하게 정해지고, 존재 조건은 일관성 등식 L\_P L\_D^{-1}Φ\_D = Φ\_F이다. Φ\_D ≡ 0이면(1차원 방향 편향 고리) E\_1 = const라 Φ\_F = 2JδJΣχ\_i ≠ 0과 모순이다. Φ\_F ≡ 0이면 E\_1은 E의 보존량(반전에 짝)이어야 하므로 반전에 홀인 Φ\_D가 0이 되어 G0이다. 두 비율이 모두 0이 아닌 일반 경우는 열린 문제이다.

**LL 꼴 (고정 T, 비섭동적).** LL 비상반 계수가 α와 무관하면 α¹ 계수에는 상반 감쇠와 잡음만 남는다. 따라서 ∇·(π'∇E\_1) = 0, 즉 ∫π'|∇E\_1|² = 0이 되어 E\_1 = const이고, α⁰ 조건은 두 채널 모두 G0일 것을 요구한다. 비상반성이 α¹ 그룹에 섞이는 Gilbert 꼴만 어려운 경우이다.

**(II)의 재해석.** 정리 1에 의해 S×H는 발산이 없으므로, (II)는 E'이 감쇠 없는 비상반 세차 Ṡ = −γS×(h^R + h^N)의 보존량이라는 조건과 같다. 온도가 들어가지 않는다. 1차 섭동에서는 다음 코호몰로지 방정식이 된다.

```latex
X_E(E_1)=\gamma\,\Phi_F,\qquad X_E=\tfrac{\gamma}{\mu}\,\mathbf S\times\nabla E
```

**보조정리 (궤도 장애물).** X\_E의 주기 궤도 Γ 위에서 ∮X\_E(E\_1)dt = 0이므로, 해가 있으려면 모든 주기 궤도에서 ∮Φ\_F dt = 0이어야 한다. 반사 대칭인 깁스형 불변 측도로는 장애물이 생기지 않으므로 손대칭 궤도가 필요하다.

**원뿔 나선.** 브라베 격자에서 등방 교환에 z축 이방성 K와 장 B가 있으면, 원뿔 나선은 z축 둘레 강체 세차를 하는 정확한 주기 궤도이다. 유효장이 h^R\_j = J\_q S\_j + A ẑ, A = c(J₀ − J\_q + 2K) + B 꼴이기 때문이다. 그 위에서 Φ\_F는 상수이다.

```latex
\Phi_F=-\mu A\,N_s\,s^2\Big[\sum_{\mathbf r}\delta J(\mathbf r)\sin\mathbf q\cdot\mathbf r+\sum_{\mathbf r}\delta D(\mathbf r)\cos\mathbf q\cdot\mathbf r\Big]
```

(δD는 n ∥ ẑ 성분, δΓ의 ẑẑ 성분은 사인 변환에 −1/3이 붙는다.) 비상반 결합이 0이 아니면 이 변환은 열린 조밀 집합의 q에서 0이 아니고, c를 골라 A ≠ 0으로 만들 수 있다.

**정리 A″ (1차, 모든 온도).** 브라베 격자, 등방 교환(+ 같은 축의 이방성과 장), 병진 불변인 쌍선형 N ≠ 0이 Gilbert 꼴로 들어가면, α에 무관한 E' = E + E\_1 + O(N²)은 어떤 온도에서도 존재하지 않는다. 물리적 의미는, 비상반 FL 결합이 강체 세차하는 손대칭 나선에 그 손대칭성에 따라 부호가 바뀌는 일정한 비율로 에너지를 주입한다는 것이다. 이는 고온 키랄성 선택과 같은 물리이다.

**수치 확인.** 1차원 사슬(최근접 + 차근접)과 2차원 정사각 격자(최근접 + 대각)에서 δJ(홀)와 δD(짝)를 함께 넣고 이방성과 장을 준 경우를 계산했다. 격자와 정합하는 네 개의 q에서 Φ\_F가 위 식과 상대오차 10^-16 수준으로 일치했고, 나선이 강체 세차 해라는 것도 10^-15 수준으로 확인했다.

**남는 부분.** 비브라베 격자나 DMI·일반 이방성이 있는 E에서는 원뿔 나선이 정확한 해가 아니므로 손대칭 주기 궤도를 따로 찾아야 한다. 고정 T의 비섭동적 경우는 비상반 세차에 매끄러운 보존량이 없음을 보이는 적분 가능성 문제로 남는다.

**정리 B (축대칭 SOT, 정확한 G2).** 고정 편극 σ̂를 향하는 자리별 감쇠형 토크는 LL에서 기울기와 σ̂ 축 회전으로 나뉜다. E가 σ̂ 축 U(1) 대칭이면 정상분포는 정확히 다음이다. 거대 스핀의 STT 유효 에너지(Li–Zhang 2004, Apalkov–Visscher 2005)를 격자로 확장한 결과이다.

```latex
E'=E-\frac{\mu}{\alpha}\sum_i\mathcal A(\mathbf S_i\cdot\hat\sigma),\qquad \mathcal A'(x)=a(x)
```

**4.2 선형 영역: 유효 DMI.** FL 채널은 감쇠율을 Γ\_k = αω\_k + ck로 바꾼다. 잡음이 고정되어 있으므로 분포는 국소 DMI를 가진 것처럼 보인다(G2).

```latex
\varepsilon'_k=\varepsilon_k-\frac{2\,N^{\mathrm{FL}}}{\alpha}\sin k,\qquad D_{\mathrm{eff}}\propto\frac{\beta-\alpha}{\alpha}\,\delta J^{\mathrm{DL}}
```

ε'\_k < 0인 구간은 Γ\_k < 0인 구간과 정확히 같아, 전류 구동 스핀파 불안정성 문턱과 일치한다.

**4.3 고온: 키랄성 장.** αk\_BT ≫ J이면 L† ≈ Λk\_BTΔ이고, 곱공간 라플라시안은 국소성을 보존한다. 1차원 FL δJ에서 다음을 얻는다.

```latex
E_1=-\frac{J\,\delta J}{3\alpha k_BT}\sum_i\mathbf S_{i-1}\cdot(\mathbf S_i\times\mathbf S_{i+1}),\qquad \langle\chi_i\rangle\approx\frac{2}{27}\,\frac{\beta^{2}J\,\delta J}{\alpha}
```

의미: 비상반 흐름은 에너지를 높이는 방향으로 확률을 운반하므로 dE\_N/dt > 0인 배위가 선택된다. 2차원 DL δJ는 반전에 홀인 3체 항을 준다. 고차에서는 지지 영역이 차수마다 넓어져 G3가 된다.

| 경우 | 등급 | 유효 에너지 |
| --- | --- | --- |
| 장형 SOT | G1 (원래 보존력) | E − μb Σ σ̂·S\_i |
| 감쇠형 SOT, U(1) 대칭 | G2 (정확) | E − (μ/α) Σ A(S\_i·σ̂) |
| 감쇠형 SOT, 축 어긋남 또는 DMI | G3 | 순환 확률류 |
| FL δJ, 스핀파 영역 | G2 | D\_eff ∝ (β−α)/α |
| FL δJ, 고온 | G3 (선도 차수 국소) | 키랄성 장 ∝ JδJ/(αk\_BT) |
| DL δJ, d ≥ 2 | G3 (격자 척도) | 3체 항 ∝ 1/(αk\_BT) |

## 5. 유효 DMI와 Walker breakdown

스핀파의 유효 DMI와 도메인벽의 Walker 문턱은 같은 좌표계 불변량으로 결정된다.

```latex
u_{\mathrm{eff}}\equiv\frac{\beta-\alpha}{\alpha}\,u
```

**5.1 좌표계 불변성.** 속도 v로 움직이는 좌표계에서 Zhang–Li 잔여 토크는 (v−u)∂m + (βu−αv) m×∂m이다. LL의 FL 성분 ∝ (β−α)u는 어떤 v로도 지워지지 않는다. 유효 DMI를 진동수 단위로 쓰면 정확히 u\_eff이다.

```latex
\varepsilon'(q)=\frac{\mu}{\gamma}\big[\omega_q+u_{\mathrm{eff}}\,q\big]
```

**5.2 벽의 빨래판.** v = (β/α)u인 벽 좌표계에서 잔여 토크는 순수 단열항 u\_eff ∂m 하나이다. 정상해 조건에서 α가 빠지므로, 문턱은 1차원 모형을 넘어 일반적으로 u\_eff에만 의존한다. 집단 좌표로 쓰면 Adler 방정식이 된다.

```latex
\dot\phi=-\frac{\alpha}{1+\alpha^2}\,\partial_\phi U,\qquad U(\phi)=-\frac{u_{\mathrm{eff}}}{\Delta}\,\phi-\frac{\gamma H_\perp}{4}\cos2\phi
```

|u\_eff| ≤ γH\_⊥Δ/2이면 벽은 v = (β/α)u로 움직이고, 넘으면 φ가 회전한다. β = 0이면 Tatara–Kohno 고유 고정 문턱이 된다.

**5.3 실제 DMI와의 차이.** 실제 계면 DMI는 φ에 주기적인 −D cos φ를 주어 Walker 장을 높인다. 전류의 유효 항은 φ에 선형인 감김 항이라 원 위에서 단일값이 아니다. 그래서 문턱 아래 유한 온도에서는 확률류가 원을 돈다(전역 G3). 극소 근처에서만 국소 G2이다.

**5.4 통일된 Landau형 기준.** 불안정 조건은 ω\_q − |u\_eff|q < 0이다.

```latex
u^{*}_{\mathrm{bulk}}=\gamma\sqrt{D_{\mathrm{ex}}}\big(\sqrt{H_e}+\sqrt{H_e+H_\perp}\big),\qquad u^{*}_{\mathrm{wall}}=\frac{\gamma}{2}H_\perp\sqrt{D_{\mathrm{ex}}/H_e}
```

```latex
\frac{u^{*}_{\mathrm{wall}}}{u^{*}_{\mathrm{bulk}}}=\frac{H_\perp}{2\sqrt{H_e}\big(\sqrt{H_e}+\sqrt{H_e+H_\perp}\big)}
```

H\_⊥ ≪ H\_e이면 Walker breakdown이 먼저 오고, H\_⊥ ≫ H\_e이면 벌크 스핀파 불안정이 먼저 온다. 이 비는 이방성 비만의 함수이다.

**5.5 열적 위상 미끄러짐.** 문턱 아래 평균 회전 속도는 기울어진 빨래판의 정확한 Fokker–Planck 해로 주어진다. 이동도는 Γ\_φ = α/\[(1+α²)2Δ\], 장벽은 2u\_c sin²φ이다. 벽 속도의 열적 보정은 다음과 같다.

```latex
\langle\dot q\rangle=\frac{\beta}{\alpha}u-\frac{\Delta}{\alpha}\langle\dot\phi\rangle
```

## 6. DMI와 비상반 교환의 복소 게이지 통일

DMI는 마그논 복소 게이지장의 실수부(위상 비대칭), 비상반 교환은 허수부(크기 비대칭)이며, 전류는 둘을 섞어 보상점을 두 개로 가른다.

**6.1 복소 호핑.** 정렬축 m₀ ∥ d̂ 주위에서 a𝟙 + b\[d̂\]× 결합은 복소수 t = a + ib로 작용한다. 상반 조건 A\_ji = A\_ij^T는 마그논 호핑의 에르미트성 t\_ji = t\_ij\*와 같다.

| 결합 | t\_ij | t\_ji | 성격 |
| --- | --- | --- | --- |
| J | J | J | 에르미트 |
| D (∥ d̂) | iD | −iD | 에르미트 |
| δJ | δ | −δ | 반에르미트 |
| δD (같은 방향 회전) | iδD | iδD | 반에르미트 |

```latex
t_{ij}=Je^{iA},\quad t_{ji}=Je^{-iA},\quad A=\phi+i\eta\ \Rightarrow\ D=J\sin\phi,\ \ \delta J\simeq J\sinh\eta
```

실수 게이지는 회전 게이지 변환으로, 허수 게이지는 크기 조절로 1차원에서 제거된다. 고리에서 남는 실수 선속은 DMI 좌절, 허수 선속은 진짜 비상반성이다.

**6.2 β = 0 단열항과 DMI의 등가.** Zhang–Li 선형 분산은 다음과 같다.

```latex
(1+\alpha^2)\,\Omega_q=\omega_q+(1+\alpha\beta)\,uq+i\big[\alpha\omega_q+(\alpha-\beta)\,uq\big]
```

진동수의 홀 항과 분포의 홀 항이 같아지는 유일한 조건은 β = 0이다. 이때 단열항은 d̂ ∥ m₀인 DMI와 같다(G1). 따라서 전류는 다음과 같이 분해된다.

```latex
\mathrm{ZL}(u,\beta)=\underbrace{\text{boost }v=(\beta/\alpha)u}_{\text{분포 불변}}+\underbrace{\text{DMI 등가 항 }(1-\beta/\alpha)\,u}_{\text{진동수·분포 동시 이동}}
```

boost 속도는 Walker 이하 벽 속도와 같고, DMI 등가 항은 −u\_eff이다.

**6.3 한계: 고정된 d̂와 따라가는 d̂.** 실제 DMI의 d̂는 스핀–궤도 결합으로 격자에 고정된 SU(2) 게이지장이다. 단열항의 실효 d̂는 자화를 따라가는 창발 게이지장이다. 그래서 자화 반전 시 DMI의 비상반 방향은 뒤집히지만 전류의 것은 그대로이고, 벽에서는 DMI가 정적인 반면 전류는 벽을 구동한다. 정적 DMI를 흐름으로 쓰려면 스핀 편극이 고정축에 묶인 평형 스핀류가 필요하다(Kikuchi 등 2016; Freimuth 등 2017).

**6.4 두 보상점과 β 측정.** DMI 자성체에 전류를 걸면 진동수 보상점과 분포 보상점이 갈라진다.

```latex
u_f=-\frac{2D}{1+\alpha\beta},\qquad u_d=-\frac{2D\,\alpha}{\alpha-\beta},\qquad \frac{u_f}{u_d}=\frac{\alpha-\beta}{\alpha(1+\alpha\beta)}
```

u\_f에서는 진동수 비상반성이 사라지고 감쇠 비상반성 −2Dβ(1+α²)/(1+αβ)가 남는다. u\_d에서는 분포가 상반이 되고 진동수에는 순수 도플러 (β/α)u만 남는다. 즉 DMI 없는 평형 마그논 기체를 움직이는 좌표계에서 본 것과 같다. 두 전류의 비와 α로 β를 구할 수 있다.

## 7. 수치 검증

모든 해석적 예측은 확률 LLG(Stratonovich Heun, 회전 적분) 계산과 맞춤 매개변수 없이 일치한다. 남은 차이는 모두 다음 차수 보정이나 1차원 강체 벽 모형의 한계로 설명된다.

## 8. 논의, 실험 제안, 남은 과제

이 틀의 판별 가능한 예측은 "전류가 만드는 유효 에너지는 1/α에 비례한다"와 "보상점이 둘로 갈라진다"의 두 가지이다.

**실험 제안.**

1. **β 측정**: DMI 박막에서 BLS 진동수 비상반성이 사라지는 전류 u\_f와, 열 마그논 점유 또는 감쇠 길이 비대칭이 사라지는 전류 u\_d를 잰다. 비 u\_f/u\_d와 α로 β를 구한다.
2. **유효 DMI의 α 의존성**: α가 다른 시료에서 전류 유도 비상반 분포가 (β/α − 1)에 비례하는지 확인한다.
3. **열적 Walker 크리프**: 문턱 아래 벽 속도의 열적 보정 (Δ/α)⟨φ̇⟩를 온도 함수로 측정해 빨래판 장벽 ∝ (u\_c − u\_eff)^{3/2}를 확인한다.
4. **문턱 순서**: 이방성 비 H\_⊥/H\_e를 바꾸며 Walker breakdown과 벌크 스핀파 불안정 중 어느 것이 먼저 오는지 본다.

**남은 과제.**

- [ ] 2차원 DL 채널 고온 3체 항 계수 1/10의 수치 검증
- [ ] 축대칭 SOT 정확 G2(정리 B)의 격자 수치 검증
- [ ] 정리 A′의 고정 온도 경우: 비브라베 격자·일반 이방성 E로의 확장(손대칭 주기 궤도), 비상반 세차의 보존량 부재(비섭동적)를 증명
- [ ] 쌍극자 상호작용을 넣은 박막 분산에서 u\_f/u\_d 보정
- [ ] Kramers 장벽 스케일링 ln⟨φ̇⟩ 대 1/T
- [ ] 2차원 LRO 포화의 L ≥ 512 확인과 K\_eff 지수 정밀화, 전체 LLG에서 자유 결함 밀도 n\_f 측정

## 9. 2차원: 장거리 질서와 결함 수송

2차원에서 장거리 질서는 편향 방향이 무엇에 묶이느냐로 갈리고, 결함 쌍의 상대 운동은 다시 u\_eff 하나로 결정된다.

**9.1 연속 이론.** x 방향 고정 편향의 과감쇠 XY 모형을 전개하면 다음을 얻는다. 스핀 반전 대칭이 (∇θ)² 항을 금지하고, (∂\_xθ)³은 2차원에서 irrelevant하다.

```latex
\dot\theta=K\nabla^2\theta+v\,\partial_x\theta-\lambda_3(\partial_x\theta)^3+\xi,\qquad K=Ja^2,\ v=2a\delta,\ \lambda_3=a^3\delta/3
```

| 편향 방향 | 연속 항 | 질서 |
| --- | --- | --- |
| 고정 (전류), DL 채널 | 선형 이류 (v·∇)θ | QLRO 유지: 깁스 분포이므로 Mermin–Wagner 성립 |
| 고정, FL 채널, 용이면 | 복소 용수철 상수 Kk² − iνk\_x | QLRO, K\_x 증가 |
| 스핀에 묶임, δJ\_ij ∝ (S\_i+S\_j)·ê\_ij | 자기 이류 v₀(n·∇)θ | 장파장 강성 증가, LRO 후보 |

**9.2 FL 채널의 이방적 강성.** 용이면 자성체의 선형 모드는 감쇠 진동자 θ̈ + Γθ̇ + (Kk² − iνk\_x)θ = η이다. Lyapunov 방정식의 정확해는 다음과 같다. θ가 실수장이라 1차 홀 항이 상쇄되므로, 원편광 마그논의 유효 DMI와 달리 2차 효과만 남는다.

```latex
\langle|\theta_k|^2\rangle=\frac{T}{Kk^2+(\nu^2/\Gamma^2)\,k_x^2},\qquad K_x^{\mathrm{eff}}=K+\nu^2/\Gamma^2,\quad \nu/\Gamma\propto u_{\mathrm{eff}}
```

**9.3 스핀에 묶인 편향.** 질서 방향을 x로 두면 자기 이류가 수직 방향 Burgers 항 (v₀/2)∂\_y(φ²)를 만든다. 결합상수 g(L) = (λ²T/K³)L²는 2차원에서 relevant하다. 자기무모순 추정 K\_eff ∝ L^{2/3}을 쓰면 ⟨φ²⟩가 수렴하여 LRO가 된다.

```latex
m\sim\Big(\frac{a}{L_\times}\Big)^{T/4\pi K}\propto v_0^{\,T/4\pi K},\qquad L_\times\sim\frac{K^{3/2}}{\lambda\,T^{1/2}}
```

**9.4 결함 쌍의 상대 좌표 (정확).** STT가 있는 Thiele 방정식에서 G₊ = −G₋ = G인 쌍의 질량중심을 소거하면 다음을 얻는다.

```latex
\dot{\mathbf r}=-2\mu_r\nabla_{\mathbf r}\Big[U(r)+G\,(\hat z\times\mathbf u_{\mathrm{eff}})\cdot\mathbf r\Big],\qquad \mu_r=\frac{\alpha D}{\alpha^2D^2+G^2}
```

상대 좌표는 로그 인력 U = 2πK ln(r/a)에 기울기 f = G|u\_eff|가 걸린 경사 흐름이다. β = α이거나, G = 0(핵 편극 없음)이거나, G₊ = G₋(핵 편극이 반대)이면 상대 구동이 없다. 장벽 r\* = 2πK/f를 넘는 열적 해리에서 다음이 나온다.

```latex
n_f\propto|G\,u_{\mathrm{eff}}|^{\pi K/T},\qquad \xi\propto|u_{\mathrm{eff}}|^{-\pi K/2T}
```

이는 초전도 박막의 전류 유도 소용돌이 해리(Halperin–Nelson)와 같은 구조이다. β ≠ α인 전류는 T\_BKT 아래에서도 QLRO를 유한 상관 길이로 바꾼다.

## 10. 속도 결합: Onsager–Casimir 쌍대성과 잡음의 짝

속도 결합에서는 장 결합과 역할이 뒤바뀐다. 대칭 부분이 소산하고 반대칭 부분은 일을 하지 않으며, 평형이 나오려면 잡음 모형이 결합 구조와 짝을 맞춰야 한다.

**10.1 설정과 에너지 수지.** 비국소 Gilbert 감쇠를 일반화하면 접공간에서 다음과 같이 쓸 수 있다. M을 대칭 부분 D와 반대칭 부분 Ω로 나눈다.

```latex
(J+A_T)\,\dot{\mathbf S}=-\tfrac{\gamma}{\mu}\nabla E,\qquad \frac{dE}{dt}=-\frac{\mu}{\gamma}\,\dot{\mathbf S}^{T}\mathsf D\,\dot{\mathbf S}
```

반대칭 부분 Ω는 에너지를 정확히 보존하는 자이로 결합이다. 상수 C\_ij로 주어지면 ω\_C = Σ C\_ij dS\_i ∧ dS\_j는 닫힌 2-형식이므로, 감쇠 없는 동역학은 ω\_J + ω\_C에 대한 해밀턴계이다.

**10.2 Onsager–Casimir 원리.** S는 시간반전에 홀, Ṡ는 짝이다. 따라서 장 결합(ε\_iε\_j = +1)은 대칭 부분이, 속도 결합(ε\_iε\_j = −1)은 반대칭 부분이 평형과 양립한다. 행렬로는 비상반으로 보이는 반대칭 속도 결합이 Onsager–Casimir 의미에서는 상반이다.

| 결합 | ε\_iε\_j | 평형이 허용하는 부분 | 평형을 깨는 부분 |
| --- | --- | --- | --- |
| 장 결합 (S\_j → h\_i) | +1 | 대칭 (J, D, Γ) | 반대칭 (δJ, δD, δΓ) |
| 속도 결합 (Ṡ\_j → h\_i) | −1 | 반대칭 (자이로) | 대칭은 잡음과 짝이 맞지 않을 때 |

**10.3 요동–소산.** M = J + Ω + D에서 sym(M⁻¹) = M⁻¹DM⁻ᵀ이므로, 잡음 공분산은 D에만 비례하면 되고 Ω와는 무관하다.

**10.4 대칭 부분: 모드별 온도.** 비국소 감쇠 α'\_k에 자리별 독립 잡음을 쓰면 모드마다 온도가 달라진다.

```latex
T_k=\frac{T\,\alpha}{\alpha+\alpha'_k},\qquad \varepsilon'_k=\varepsilon_k\Big(1+\frac{\alpha'_k}{\alpha}\Big)
```

물리적 열원(스핀 펌핑의 전자 열원)이 평형이면 상관 잡음 ⟨ξ\_iξ\_j⟩ ∝ α\_ij가 자연스럽게 따라온다. 시뮬레이션에서 비국소 감쇠를 넣을 때는 잡음도 상관시켜야 한다.

**10.5 반대칭 부분: 리우빌 측도와 √det M.** 열역학적으로 일관된 평형은 리우빌 측도 위의 정준 분포이다. 등방형 c\_ij에서 2차까지 전개하면 온도에 비례하는 엔트로피성 반강자성 교환이 나온다.

```latex
p_{\mathrm{정준}}\propto e^{-\beta E}\sqrt{\det(J+\Omega)},\qquad E'=E+k_BT\sum_{i<j}c_{ij}^2\,\mathbf S_i\cdot\mathbf S_j
```

반면 국소 Stratonovich 잡음의 확률 LLG는 감쇠가 섞인 행렬식을 준다. Itô로 변환하고 확률류를 J = T∂(pΛ\_a) 꼴로 두면, ∂\_a ln ρ = ∂\_jM\_ab Λ\_a^{bj}가 된다. D가 상수이고 W = J + Ω가 닫힌 형식이면 이 우변이 ½∂\_a ln det M과 같아진다.

```latex
p_{\mathrm{naive}}\propto e^{-\beta E}\sqrt{\det(J+\Omega+\mathsf D)},\qquad E'_{\mathrm{naive}}=E+\frac{k_BTc^2}{(1+\alpha^2)^2}x-\frac{k_BTc^2\alpha^2}{2(1+\alpha^2)^2}x^2
```

Ω = 0이면 det(J + α)가 상수라 두 분포가 일치한다. 표준 확률 LLG가 맞는 것은 자이로 결합이 없을 때뿐이다. 자이로 결합이 있으면 잡음 유도 드리프트를 보정해 √det M을 √det(J+Ω)로 바꿔야 한다. 질량 0 극한에서 로런츠 힘이 일으키는 문제와 같은 구조이다. 토크 결합은 실제 속도 대신 세차 속도에 결합하므로 1차에서는 같고 O(C²)에서 갈라지며, 곱 넓이 측도를 정확히 보존한다.

| --- | --- | --- |

| 속도 결합은 √det M 가중치 | 이합체, J = 0, (α, c) = (0.4, 0.35), (1, 0.5), (2.5, 0.9) | −0.0294, −0.0192, −0.0058 / 예측 −0.0296, −0.019, −0.0045 (리우빌 −0.041, −0.083, −0.270) |

**남은 과제.** 구면 위에서 D = αg가 상수가 아니므로 곡률 항이 추가된다. 국소 Gilbert에서처럼 이 항들이 상쇄된다는 공변 증명은 아직 하지 않았으며, 현재는 세 가지 α의 수치 일치로 뒷받침된다.

## 11. 받는 스핀에 의존하는 결합: 수축과 정리 1′

등방 쌍 토크는 각도 의존성이 아무리 복잡해도 두 스칼라 함수로 완전히 기술되며, 위상공간 수축은 그중 감쇠형 성분의 대칭 부분만으로 정해진다. 그 부분이 0이 아니면 어떤 온도에서도 볼츠만 분포가 깨진다.

**11.1 완전한 분해.** 스핀 회전에 공변인 쌍 토크의 Hodge 퍼텐셜은 x = S\_i·S\_j만의 함수이므로 다음과 같이 쓸 수 있다. 첫 항은 넓이를 보존하는 해밀턴 성분, 둘째 항은 감쇠형 기울기 성분이다.

```latex
\mathbf T_{i\leftarrow j}=f_{ij}(x)\,\mathbf S_i\times\mathbf S_j+g_{ij}(x)\,P_i\mathbf S_j,\qquad f=\phi',\ g=\psi'
```

르장드르 전개에서 n = 0이 쌍선형(FL δJ는 반대칭 f₀, DL δJ는 반대칭 g₀)이고, n ≥ 1이 받는 스핀에 의존하는 성분이다. 비상반 성분을 교환 대칭으로 δf^{s,a}, δg^{s,a}로 나눈다.

**11.2 수축률.** x만의 함수에 대한 구면 라플라시안은 르장드르 연산자이므로, 쌍 하나의 수축 기여는 g의 대칭 부분만으로 정해진다.

```latex
\sigma_{\text{쌍}}=\mathcal L(\psi_{ij}+\psi_{ji})=2\frac{d}{dx}\Big[(1-x^2)\,g^s(x)\Big],\qquad \mathcal L=\frac{d}{dx}(1-x^2)\frac{d}{dx}
```

**정리 1′.** 볼츠만 분포가 보존되면 δg^s ≡ 0이다(온도와 무관). 그러면 σ ≡ 0이고 문제는 dE\_N/dt ≡ 0으로 환원된다. 증명: 세 자리 항을 셋째 스핀에 대해 평균하면 두 자리 성분이 0이므로(ANOVA 분해) 쌍마다 두 자리 조건이 따로 성립해야 한다. u = (1−x²)Ψ', Ψ = ψ\_ij + ψ\_ji로 두면 조건은 u' = βε'u, 즉 u = C e^{βε}이다. 토크가 매끄러우면 u(±1) = 0이므로 C = 0이다. 위상공간을 수축시키는 비상반성은 에너지 펌프로 상쇄될 수 없으며, 특정 온도에서만 평형인 등방 쌍 결합은 존재하지 않는다.

| 성분 | 위상공간 | 물리적 그림 | 볼츠만 |
| --- | --- | --- | --- |
| δf^s | 보존 | 감쇠 짝이 없는 추가 해밀턴 세차 | {E, δE} = 0일 때만 |
| δf^a | 보존 | FL δJ의 각도 의존 일반화, 키랄성 펌프 | 이분 격자 γ 재정의만 |
| δg^s | 수축 | 서로를 같은 쪽으로 끄는 상호 감쇠·반감쇠 | 불가 (정리 1′) |
| δg^a | 보존 | 하나는 끌고 하나는 밀어내는 추격–도주 | 1차원 이류형과 이합체만 |

각도 의존 Slonczewski 토크(g₁₂ = a₁(x), g₂₁ = a₂(x))는 a₂ = −a₁이면 순수 g^a라 이합체에서 볼츠만이 유지되고, 두 층의 각도 함수가 다르면 g^s ≠ 0이라 반드시 비평형이다.

**11.3 이합체의 정확한 정상분포.** 회전 불변성 때문에 정상분포는 x만의 함수이다. 해밀턴 성분(f)은 x를 바꾸지 않고 발산도 없으며, 감쇠형 성분의 수축률은 σ = dẋ/dx로 쓰인다. 따라서 Fokker–Planck 방정식은 1차원 보존 형태가 된다.

```latex
\frac{d}{dx}\Big[\dot x\,p-2D(1-x^2)\,p'\Big]=0,\qquad \dot x=(1-x^2)\big[-2\Lambda\varepsilon'(x)+a_1(x)+a_2(x)\big]
```

경계 x = ±1에서 확률류가 0이고 D = Λk\_BT이므로, Gilbert 꼴 토크 a\_i에 대해 정확히 다음을 얻는다.

```latex
p(x)\propto\exp\big[-\beta E'(x)\big],\qquad E'(x)=\varepsilon(x)-\frac{\mu}{2\alpha\gamma}\int^{x}\!\big[a_1(x')+a_2(x')\big]dx'
```

대칭 부분 g^s만 남고 반대칭 부분은 사라진다. E'은 국소적이고 T와 무관하지만 1/α에 의존하므로 정확한 G2이다. 한 스핀이 고정된 경우(기준층 고정)에는 상대각 확산이 절반이 되어 계수가 μ/(αγ)가 되고, 이는 정리 B의 축대칭 SOT 결과와 같다.

| 토크 | 시뮬레이션 ⟨x⟩ | 정확한 예측 | 일반 깁스 |
| --- | --- | --- | --- |
| a₁ = 0.4 + 0.3x, a₂ = −0.1 | 0.3618 | 0.3594 | 0.3130 |
| a₂ = −a₁ (순수 g^a) | 0.3156 | 0.3130 | 0.3130 |
| a₁ = −0.5, a₂ = −0.5x² | 0.2281 | 0.2256 | 0.3130 |

세 경우 모두 시간 간격에 의한 공통 편향 +0.0025를 빼면 통계 오차(±0.0015) 안에서 일치한다.

**남는 부분.** 스핀–궤도 벡터가 있는 비등방 경우에는 두 자리 조건이 쌍의 가역 생성자에 대한 타원형 방정식이 되지만, 해밀턴 성분의 포아송 괄호 항 때문에 위의 경계 조건 논법을 그대로 쓸 수 없다. 삼체 결합 K\_ijk S\_j × S\_k는 세 자리 수축 성분을 가질 수 있어 별도 분석이 필요하다.
