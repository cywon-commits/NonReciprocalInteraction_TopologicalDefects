# 분기 논문 A: 비상반 결합과 위상 구조 — 위상 전하 선택 규칙과 열적 스커미온 쌍 통계 (구조안)

Oct 5, 2026 · Changyeon Won (Kyung Hee University)

## 제목 후보와 초록

핵심 주장: 비평형에서는 세차가 시간반전 깨짐을 공급하므로, 위상 전하 ⟨Q⟩의 선택 규칙은 "평면의 방향을 뒤집는 연산이 모두 깨졌는가" 하나로 정해진다. 공간 분포는 흐름 함수가, 전체 전하는 소용돌이도가 결정한다.

**제목 후보**

1. Topological charge selection by nonreciprocal spin couplings: gyrotropy replaces the magnetic field
2. Vorticity, stream function, and thermal skyrmion statistics under spin currents
3. 비상반 스핀 결합의 위상 전하 선택 규칙과 열적 스커미온 쌍 통계

**초록 초안**

평형 자성체에서 순 위상 전하가 생기려면 시간반전을 깨는 자기장과 거울을 깨는 스핀–궤도 결합이 모두 필요하다. 우리는 비상반 스핀 결합이 있는 확률 LLG의 정상 측도에 대해 이 조건을 다시 유도한다. 비고유 스핀 변환은 세차 부호만 뒤집으므로, 비평형에서는 세차 자체가 시간반전 깨짐을 공급하고 자기장 없이도 ⟨Q⟩ ≠ 0이 가능하다. 남는 조건은 평면 방향을 뒤집는 연산이 모두 깨지는 것뿐이다. 이로부터 균일한 극성 편향 δJ와 스핀–궤도 결합 없는 δD는 모든 차수에서 ⟨Q⟩ = 0이고, 흐름의 소용돌이도나 면에 수직인 δD와 DMI의 조합만이 순 전하를 만든다는 선택 규칙을 얻는다. 고온에서는 위상 밀도가 소용돌이도와 국소적으로 결합하고, 저온에서는 스커미온이 흐름 함수를 퍼텐셜로 느낀다. 2차원 하이젠베르크 자성체에서는 모든 스커미온–반스커미온 쌍이 u\_eff = (β−α)u/α에 의해 갈라지지만, 로그 결합이 없으므로 해리는 열활성 과정이 아니다. 특성 길이는 k\_BT/(G|u\_eff|) 하나이며, 자유 스커미온 밀도는 선도 로그 차수에서 전류에 무관하고 효과는 쌍 상관의 방향성과 가장자리 축적으로 나타난다.

## 1. 서론

기초 논문은 결함 쌍의 상대 좌표가 기울어진 로그 퍼텐셜의 경사 흐름임을 보였다. 이 논문은 그 기울기를 흐름 함수로 일반화하고, 순 위상 전하가 언제 생기는지를 대칭으로 판정한다.

**이미 확보한 결과.**

- 결함 쌍의 상대 좌표는 로그 인력에 기울기 G u\_eff가 걸린 경사 흐름이다. u\_eff = (β−α)u/α이다.
- 같은 핵 편극 쌍만 상대 구동되며, 해리로 n\_f ∝ |G u\_eff|^{πK/T}가 된다.
- Walker breakdown은 벽 각도의 원 위 감김 항이고, 유한 온도에서 확률류가 원을 돈다(전역 G3).
- 1차원 고온에서 ⟨χ⟩ ≈ (2/27)β²JδJ/α이다. χ는 시간반전에 홀이지만 장 없이 0이 아니다.

**질문.**

1. 어떤 비상반 결합이 순 위상 전하 ⟨Q⟩를 허용하는가? 평형에서 필요한 자기장은 비평형에서도 필요한가?
2. 위상 밀도 q(r)는 구동 흐름의 어떤 양과 결합하는가?
3. 로그 결합이 없는 2차원 하이젠베르크 스커미온 쌍에서 해리 통계는 소용돌이 쌍과 어떻게 다른가?

**기여.**

1. 보조정리 Q0: ⟨Q⟩는 세차 부호에 대해 홀이므로, 비평형에서는 세차가 자기장의 역할을 한다.
2. 선택 규칙: 균일 δJ와 SOC 없는 δD는 모든 차수에서 ⟨Q⟩ = 0이다. 소용돌이도, 그리고 n\_z와 DMI의 조합만 순 전하를 허용한다.
3. 고온에서 위상 밀도가 소용돌이도와 결합하는 격자 계수를 정확히 구한다.
4. 저온에서 스커미온 정상분포가 흐름 함수의 볼츠만 꼴임을 보인다. 이는 기울어진 퍼텐셜의 일반화이다.
5. 하이젠베르크 스커미온 쌍의 해리 길이 ℓ\_u = k\_BT/(G|u\_eff|)를 구하고, 소용돌이와 대비한다.

## 2. 대칭 논증: 위상 전하 선택 규칙

비평형에서 ⟨Q⟩ ≠ 0의 조건은 "평면 방향을 뒤집는 연산이 정상 측도의 대칭으로 남지 않는다" 하나이다. 스핀 공간의 방향은 세차가 이미 깨기 때문이다.

**2.1 Q의 두 홀짝성.** 위상 밀도는 미분 두 개와 스핀 삼중곱으로 되어 있다.

```latex
q=\frac{1}{4\pi}\,\mathbf n\cdot(\partial_x\mathbf n\times\partial_y\mathbf n),\qquad Q\;\to\;\epsilon_s\,\epsilon_\sigma\,Q
```

ε\_s는 평면 방향(거울, 면내 C₂)을, ε\_σ는 스핀 공간 방향(비고유 회전, S → −S 포함)을 뒤집을 때 −1이다.

**2.2 평형과 비평형의 대칭군.** 정상 측도는 생성자의 대칭만 물려받는다. 평형 분포 e^{−βE}는 E의 대칭을 모두 갖고, 쌍선형 E는 S → −S에 불변이다. 그래서 자기장이 없으면 ⟨Q⟩\_eq = 0이다. LL 꼴에 비고유 스핀 변환 R을 가하면 세차항만 det R = −1을 얻는다.

```latex
\dot{\mathbf S}=-\gamma\,\mathbf S\times\mathbf h-\gamma\alpha\,\mathbf S\times(\mathbf S\times\mathbf h)\;\xrightarrow{\;R,\ \det R=-1\;}\;\gamma\to-\gamma\ (\alpha\ \text{고정})
```

**보조정리 Q0.** ⟨Q⟩는 모든 세차형 항(상반 세차와 FL 비상반 항)의 부호를 함께 뒤집는 연산에 대해 홀이다. 평형 분포는 γ에 무관하므로 이것이 곧 "장이 없으면 ⟨Q⟩ = 0"이다. 비평형에서는 세차가 시간반전 깨짐을 공급하므로 자기장이 필요 없다. 1차원 키랄성 ⟨χ⟩ ≠ 0이 이미 그 예이다.

**2.3 SOC가 없을 때 (스핀 공간군).** 실공간 연산은 자리만 옮기고 스핀은 그대로 둔다.

- 균일 δJ\_ij = δJ ê\_ij·v̂는 스핀 스칼라이면서 실공간 극성 벡터이다. v를 포함하는 거울이 정확한 대칭이므로 P(Q) = P(−Q)가 분포 전체에서, 모든 차수에서 성립한다.
- 2차원에서 벡터 하나로 만든 유사스칼라 ε\_ab v\_a v\_b는 0이다. 따라서 연속 극한에서 전류 방향과 무관하게 ⟨Q⟩ = 0이다.
- 격자에서는 격자축과 어긋난 전류에서만 Im(v\_x + i v\_y)⁴ (정사각) 또는 Im(v\_x + i v\_y)⁶ (삼각) 꼴이 허용된다.
- 균일 δD (n\_ij = n)는 스핀 공간 벡터라 실공간에 작용하지 않는다. 모든 격자 거울이 남으므로 n의 방향과 무관하게 ⟨Q⟩ = 0이다. 축 벡터라는 성질만으로는 Q를 허용하지 않는다.
- 실공간 유사스칼라를 주는 구동은 흐름의 소용돌이도 ω = ∇×v̂이다(3, 4절).

**2.4 SOC가 있을 때 (스핀–격자 결합).** 결합 연산의 스핀 부분은 축 벡터 변환이므로 항상 고유이다. 따라서 Q는 평면 내 부분의 방향으로만 변환된다. 수직 거울 M\_v와 면내 C₂′는 Q를 뒤집고, M\_z, C\_n(z), 반전은 보존한다.

- 통상 SOT (σ ∥ ẑ×j)에서는 j와 ẑ를 포함하는 거울이 남으므로 모든 차수에서 ⟨Q⟩ = 0이다. B\_z를 더하면 허용되지만 C₂z 때문에 j에 짝이라 δ⟨Q⟩ ∝ B\_z j²이다.
- 면에 수직인 편극 n\_z는 모든 M\_v와 C₂′를 깬다. 스핀 C₂z는 계면 D를 뒤집지만 Q와 n\_z는 보존하므로 ⟨Q⟩는 D에 짝이다. 따라서 ⟨Q⟩ ∝ n\_z D²이고 장이 없어도 된다.
- 평형의 알려진 결과 ⟨Q⟩\_eq ∝ B\_z D²와 같은 꼴이다. 비평형에서는 δD\_z가 B\_z의 역할을 한다.

**2.5 선택 규칙 요약.** 모든 경우에 ⟨Q⟩는 세차 부호를 가지므로, 전류 구동에서는 u\_eff에 비례하고 β = α에서 사라진다.

| 구동 | 남는 ε\_s = −1 연산 | ⟨Q⟩ |
| --- | --- | --- |
| 균일 δJ (극성 v) | v를 포함하는 거울 | 0 (모든 차수, 연속 극한) |
| 소용돌이 흐름 δJ | 없음 | ∝ u\_eff ∮v̂·dl, 선형 |
| 균일 δD, SOC 없음 | 모든 격자 거울 | 0 |
| SOT δD, σ 면내 | (j, ẑ) 거울 | 0, B\_z가 있으면 ∝ B\_z j² |
| δD\_z + 계면 DMI | 없음 | ∝ n\_z D², 선형 |
| 평형, B\_z + DMI (기준) | 없음 | ∝ B\_z D² |

**2.6 정리 문장 (검증 1단계).** 위 논증을 두 개의 정리로 고정한다. 모형 𝓜(c\_p; N^FL, N^DL; E; λ, T)는 세차 계수 c\_p를 가진 확률 LL 동역학이다.

```latex
d\mathbf S_i=\big[-c_p\,\mathbf S_i\times(\mathbf h_i+\mathbf h_i^{N,\mathrm{FL}})-\lambda\,\mathbf S_i\times(\mathbf S_i\times\mathbf h_i)+\mathbf g_i^{\mathrm{DL}}\big]dt-\sqrt{2\lambda k_BT}\;\mathbf S_i\times\circ\, d\mathbf W_i
```

**정리 Q1 (등변성).** g = (π, R)가 S\_i → R S\_{π⁻¹(i)}로 작용하고 R ∈ O(3), π는 격자 등거리 변환이라 하자. 그러면 g는 모형 𝓜(c\_p; 결합)을 𝓜(det R · c\_p; g·결합)으로 보낸다. 잡음이 (S²)^N에서 타원형이므로 정상분포는 유일하고, P\_{g𝓜} = P\_𝓜 ∘ g⁻¹이다.

- 증명: R a × R b = (det R) R(a × b)이다. 세차항은 외적 하나라 det R을 얻고, 감쇠항은 외적 둘이라 det² = 1이다.
- 잡음항의 부호는 dW → −dW가 같은 분포라 흡수된다. DL 형 기울기 항도 외적 둘이라 불변이다.

**정리 Q2 (선택 규칙).** 위상 전하가 Q ∘ g = ε\_s(π) det R · Q를 만족하도록 정의하자(아래 주의). 결합이 g에 대해 불변이면 다음이 성립한다.

```latex
\langle Q\rangle_{c_p}=\epsilon_s(\pi)\,\det R\;\langle Q\rangle_{\det R\cdot c_p}
```

- (a) 고유한 R = 1, ε\_s = −1인 g가 결합을 보존하면, 모든 온도와 모든 차수에서 ⟨Q⟩ = 0이고 P(Q) = P(−Q)이다.
- (b) 평형(N = 0)에서는 P가 c\_p에 무관한 깁스 분포이다. 쌍선형 E는 R = −𝟙에 불변이므로 ⟨Q⟩ = 0이다. 이것이 보조정리 Q0이다.
- (c) 비평형에서는 ⟨Q⟩가 c\_p 부호에 대해 홀인 성분만 가진다. 따라서 장 없이 나타나는 ⟨Q⟩는 반드시 세차가 공급한 것이다.

**적용 (SOC 없음).**

- 균일 δJ, v가 격자축 또는 대각선 방향: v를 포함하는 격자 거울이 (a)를 만족한다. ⟨Q⟩ = 0은 정확하다.
- 일반 방향 θ: C₄가 ⟨Q⟩(θ) = ⟨Q⟩(θ + π/2)를, 거울이 ⟨Q⟩(−θ) = −⟨Q⟩(θ)를 준다. 최저 조화는 sin 4θ이다. δJ에 선형인 응답은 벡터이므로 sin 4θ 계수는 δJ⁴부터이다.
- 균일 δD (n\_ij = n\_ji = n): 격자 거울은 결합 n을 그대로 둔다. 따라서 (a)에 의해 ⟨Q⟩ = 0이다.

**적용 (SOC 있음).** g의 스핀 부분은 축 벡터 변환이라 det R = +1이다. Q는 ε\_s만 얻는다. 면내 SOT 편극에서는 (j, ẑ) 거울이 (a)를 만족하고, n\_z와 계면 D가 있으면 그런 g가 없다.

**주의: 격자 Q의 정의.** 한 방향 대각선으로 고정한 Berg–Lüscher Q는 거울에 대해 배위별로 홀이 아니다. 두 대각선 분할의 평균이나 네 모서리 삼각형으로 만든 Q\_χ를 써야 정리 Q2가 배위별로 성립한다.

**2.7 SOC 경우의 계수 (다음 4).** 계면 DMI D\_ij = D(ẑ×ê\_ij)와 면에 수직인 FL 비상반 결합 h^N\_i = δD\_z ẑ×Σ\_j S\_j(N\_ij = N\_ji = δD\_z\[ẑ\]×)를 넣고, 장이 없는 상태에서 3.5절과 같은 정확 모멘트 전개를 했다. 구면 라플라시안의 역연산은 스핀별 조화 분해로 계산했다. q는 자리당 위상 전하(네 모서리 χ의 합/8π)이다.

```latex
\langle q\rangle=\frac{11}{5832\pi}\,\frac{\delta D_z\,D^2}{\lambda\,(k_BT)^3}+O(T^{-4}),\qquad \langle q\rangle_{\mathrm{eq}}=-\frac{B_zD^2}{81\pi\,(k_BT)^3}\quad\Rightarrow\quad B_{\mathrm{eff}}=-\frac{11}{72}\,\frac{\delta D_z}{\lambda}
```

- 11/729는 정적 6/729와 소산 5/729의 합이다(모서리 χ 합의 계수).
- 대칭이 요구하는 성질이 모두 확인된다. 1차 항은 0이고, D에 짝(D → −D 불변, D → D/2에서 1/4), δD에 홀이다. 이 차수에서는 J에 무관하고 세차 항은 0이다.
- 평형 기준 ⟨q⟩\_eq ∝ B\_zD²를 같은 격자와 규약으로 계산해 비교했다. δD\_z는 위상 전하에 대해 유효 자기장 B\_eff = −(11/72)δD\_z/λ처럼 작용한다.
- 1/λ 의존성은 이것이 진짜 장이 아니라 동역학적 유사장(G2)이라는 표지이다. 비통상 SOT 박막에서 ⟨Q⟩가 토크/α에 비례하는지를 보면, Oersted 장 같은 실제 장과 구별할 수 있다.

## 3. 고온 전개: 위상 밀도는 소용돌이도와 결합한다

αk\_BT ≫ J에서 유효 에너지의 위상 부분은 −κ∫ωq 꼴이다. 순 전하는 흐름의 순환에 비례하고, 균일 흐름은 격자 척도의 위상 쌍극자만 편극시킨다.

**3.1 출발식.** 1차원 결과와 같은 규약을 쓴다. 정사각 격자에서 δJ\_ij = δJ (ê\_ij·v̂\_ij)이다.

```latex
E_1=-\frac{\dot E_N^{\mathrm{FL}}}{6\,\alpha k_BT},\qquad \dot E_N^{\mathrm{FL}}=J\sum_i\sum_{j\neq k}\delta J_{ij}\,\chi_{ijk},\qquad \chi_{ijk}=\mathbf S_i\cdot(\mathbf S_j\times\mathbf S_k)
```

1차원에 적용하면 E\_1 = −(JδJ/3αk\_BT)Σχ\_i가 그대로 나온다.

**3.2 삼각형 분류.** 이웃 쌍 (j, k)에 따라 두 종류가 나온다.

- 일직선 삼중항 (i−x̂, i, i+x̂)은 1차원 키랄성, 즉 흐름 방향의 키랄성을 준다. Q와는 결합하지 않는다.
- 모서리 삼각형의 계수는 (v\_x − v\_y), (v\_x + v\_y), (−v\_x + v\_y), (−v\_x − v\_y)이다(UR, UL, LL, LR). 한 자리에서 합이 0이다.
- 한 plaquette의 네 모서리 삼각형은 서로 다른 네 자리에서 온다. 계수 합은 정확히 이산 회전 C\_p = 2a ω\_p이다. 이 결과는 q가 매끄럽다는 가정을 쓰지 않는다.

**3.3 순 전하.** 무한 온도 상관 ⟨χ\_t χ\_t′⟩ = (2/9)δ\_tt′을 쓰고 Q\_χ ≡ (1/8π)Σ\_모서리 χ로 정의하면, 격자 단위(a = 1)에서 다음을 얻는다. 부호는 χ와 LL 규약에 따른다.

```latex
\langle Q_\chi\rangle=\frac{J\,\delta J}{108\pi\,\alpha\,(k_BT)^2}\oint\hat{\mathbf v}\cdot d\mathbf l
```

Stokes 정리에 의해 균일 흐름의 순환은 0이다. 이는 2절의 대칭 결과와 일치한다. 계수가 1/α와 δJ^FL을 가지므로 전류 구동에서 u\_eff에 비례한다.

**3.4 연속 형태와 의미.** 위 결과는 다음 결합으로 요약된다.

```latex
E_1\supset-\kappa\int(\hat z\times\hat{\mathbf v})\cdot\nabla q\;d^2r=-\kappa\int\omega\,q\;d^2r,\qquad \kappa=\frac{4\pi a\,J\,\delta J}{3\,\alpha k_BT}
```

ẑ×v̂는 위상 편극에 짝인 "장"이다. 균일 흐름은 plaquette 안에서 아래 삼각형과 위 삼각형의 차, 즉 격자 척도의 위상 쌍극자를 ẑ×v̂ 방향으로 편극시킨다. 순 전하는 그 장의 발산, 곧 소용돌이도가 만든다.

**모형과 실제의 일치.** 고온 전개는 곱공간 라플라시안이 국소성을 보존한다는 사실만 쓴다. 따라서 계수의 의존성 JδJ/(αT²)과 순환 비례는 격자 세부에 무관하다. Berg–Lüscher Q와 Q\_χ의 차이는 O(1) 인수뿐이다.

**3.5 다음 차수: κ(T)의 정확한 2차 계수 (다음 3).** 구면 위 다항식의 정확한 모멘트로 ⟨χ\_t⟩를 J/T의 다음 차수까지 계산했다. 세 항은 정적(평형 측도 e^{−βE}의 1차), 소산(−λ∇E·∇), 세차(뒤집힌 세차 (S×h)·∇) 보정이다.

```latex
\langle\chi_t\rangle=-\beta\Big[\langle\chi_tE_1^{(1)}\rangle_0-\beta\langle\chi_tE_1^{(1)}E\rangle_0+\tfrac{1}{6\lambda k_BT}\langle\chi_t\,L_1E_1^{(1)}\rangle_0\Big],\qquad L_1=-\lambda\nabla E\cdot\nabla+(\mathbf S\times\mathbf h)\cdot\nabla
```

결과를 x 결합의 행별 편향 d(y)에 대한 핵으로 쓴다. 단위는 JδJ/(27λT²)이다.

```latex
\chi_{\mathrm{UR}}(y)=\Big[1+\tfrac49\tfrac{J}{T}\Big]d(y)-\tfrac49\tfrac{J}{T}\,d(y+1),\qquad \chi_{\mathrm{LL}}(y)=-\Big[1+\tfrac49\tfrac{J}{T}\Big]d(y)+\tfrac49\tfrac{J}{T}\,d(y-1),\qquad \chi_{\mathrm{chain}}=2d(y)
```

- UL은 UR과, LR은 LL과 같다. 4/9는 정적 1/3과 소산 1/9의 합이다. 일직선 χ에는 이 차수의 보정이 없다.
- plaquette 합은 2(a − b)ω\_p이므로 다음이 성립한다.

```latex
\kappa(T)=\kappa_0\Big[1+\tfrac89\,\tfrac{J}{k_BT}+O\big((J/k_BT)^2\big)\Big]
```

- 세차 보정은 이 차수에서 정확히 0이다. (S×h)·∇E₁은 S → −S에 짝이고 χ는 홀이므로 모멘트가 사라진다. 세차는 짝수 차수로만 들어오고, 따라서 κ의 λ 의존성은 (J/T)² 이상에서 시작한다. 보정은 이웃 삼각형의 χ가 평형에서 상관되기 때문에 생기는 정적 효과이다.

2단계 측정(L = 8 정현 전단)과 맞춤 없이 비교한다. J/T = 0.4, λ = 0.5, 긴 계산이다.

| --- | --- | --- |

| UR, UL sin 투영 | 1.052 | 1.011, 1.023 |

## 4. 저온 Thiele: 흐름 함수가 퍼텐셜이 된다

이동하는 스커미온의 정상분포는 u\_eff의 흐름 함수 ψ\_e에 대한 볼츠만 꼴이다. 기초 논문의 기울어진 퍼텐셜은 ψ\_e가 선형인 특수 경우이다.

**4.1 흐름 함수.** ∇·u\_eff = 0이면 ẑ×u\_eff = ∇ψ\_e로 쓸 수 있고, ∇²ψ\_e = −ω\_e이다. STT Thiele 방정식에서 w = v − (β/α)u로 두면 다음이 된다.

```latex
(\alpha\mathcal D+G\,\epsilon)\,\mathbf w=-\nabla\big[U+G\,\psi_e\big],\qquad \dot{\mathbf r}=\mathbf w+\tfrac{\beta}{\alpha}\mathbf u
```

**4.2 정확한 정상분포.** 반대칭 G ε 부분은 볼츠만 꼴을 바꾸지 않는다. 남는 이류 (β/α)u는 등-ψ 선을 따라 흐르므로(u·∇ψ ∝ u·(ẑ×u) = 0) 역시 바꾸지 않는다. 따라서 U = 0인 단일 스커미온에 대해 다음이 정확하다.

```latex
P_Q(\mathbf r)\propto\exp\!\big[-G_Q\,\psi_e(\mathbf r)/k_BT\big],\qquad G_Q=4\pi Q\,s
```

쌍에서는 상대 좌표가 G\[ψ\_e(r₊) − ψ\_e(r₋)\]를 느낀다. 균일 흐름이면 이것이 G(ẑ×u\_eff)·r, 즉 기존의 기울기 항이다.

**4.3 소용돌이도의 출처.** 균일 박막의 옴 전류는 ∇×j = 0이다. 따라서 소용돌이도는 계수의 기울기에서만 나온다.

```latex
\omega_e\propto\nabla\Big[\frac{(\beta-\alpha)P}{\alpha}\Big]\times\mathbf j
```

전류에 수직인 편극 P나 β/α의 기울기가 순 전하를 만든다. 폭 W인 띠에서는 ⟨Q⟩ ∝ L\[u\_eff(0) − u\_eff(W)\]이다.

**4.4 Corbino와 감김 항.** 반지름 방향 전류 j ∝ r̂/r에서 ψ\_e = cφ는 다가 함수이다. 스커미온은 원을 돌며 전역 확률류를 만든다. 이는 Walker breakdown의 감김 항(원 위 선형 퍼텐셜, 전역 G3)과 같은 구조이다. 중심 밖에서 ω = 0이므로 순 전하는 생기지 않는다.

**4.5 계층 구조.** 연속 동역학은 Q를 보존하므로, 전체 Q는 격자 척도의 생성과 붕괴로만 바뀐다.

- 공간 분포 q(r)는 Thiele 수송, 즉 ψ\_e가 정한다.
- 생성률과 붕괴율이 ψ\_e에 무관하면 닫힌 시료에서 N₊ = N₋이다. 수송은 재배치만 한다.
- 전체 ⟨Q⟩는 핵 척도의 국소 결합(3절, ∝ ω)이 정한다.

두 영역은 하나의 핵으로 통일된다.

```latex
E_{\mathrm{eff}}\supset\int q\,K\,\psi_e\,d^2r,\qquad K\to G\ \ (\text{이동하는 입자}),\qquad K\to-\kappa'\nabla^2\ \ (\text{격자 국소})
```

**4.6 저온에서 전체 전하를 정하는 것 (다음 1).** 저온의 전체 ⟨Q⟩는 격자 척도의 단일 생성·붕괴 사건이 가진 비대칭 B = Γ₊ − Γ₋가 정한다. 수송은 닫힌 시료에서 전하를 재배치만 하고, 쌍 생성과 소멸은 전하를 바꾸지 못한다.

*대칭.* 정리 Q2를 국소 사건률에 적용하면 B(r)는 ε\_s에 홀이고 세차 부호 c\_p에 홀이다. 구동 v(r)에 선형인 국소 유사스칼라는 ẑ·∇×v = ω 하나뿐이다. v 자체는 벡터이고 ∇·v는 스칼라이기 때문이다. SOC가 있으면 n\_z D² 항이 더해진다.

```latex
B(\mathbf r)=\Gamma_+-\Gamma_-=2g\,\lambda\,\omega(\mathbf r)+O(\nabla^2\omega,\ v^3),\qquad \lambda\simeq\kappa_{\mathrm{eff}}/k_BT\ \ (\text{가설: 유사 에너지 }-\kappa\!\int\!\omega q\text{에 대한 국소 상세균형})
```

*비율 방정식.* n±는 수송, 단일 생성 g±, 단일 붕괴 ν, 쌍 생성, 쌍 소멸 k n₊n₋을 따른다. 수송 흐름은 3단계에서 확인한 J± = −D∇n± ∓ μG n±∇ψ\_e (+ 등-ψ 이류)이다. 전하 ρ = n₊ − n₋의 방정식에서는 쌍 과정이 정확히 빠진다.

```latex
\partial_t\rho=D\nabla^2\rho+\mu G\,\nabla\!\cdot\!(s\nabla\psi_e)+B-\nu\rho,\qquad \frac{dQ}{dt}=\int B\,d^2r-\nu Q-\oint\mathbf J_q\cdot\hat n\,dl,\qquad s=n_++n_-
```

*결과.*

1. 닫힌 시료(반사 벽)에서는 Q = ∫B/ν = (2gλ/ν)∮𝐯·dl이다. 수송은 전체 전하에 기여하지 않는다. 따라서 2절의 선택 규칙(균일 흐름에서 0, 순환에 비례)은 저온에서도 성립한다.
2. 열린 가장자리(스커미온이 빠져나감)에서는 가장자리 스커미온 Hall 흐름 −μG s∮∂\_nψ\_e dl이 더해진다. 균일한 s에서 이 항은 μG s∫ω\_e d²r이다. 이 항도 ∮u\_eff·dl에 비례하므로 선택 규칙은 그대로이고, 계수만 경계 조건에 따라 달라진다.
3. 국소 전하 밀도는 선형 응답(s ≈ 2n̄)에서 다음과 같다. 4.5절 핵 K의 두 극한 사이 교차 길이는 ℓ\_ν = (D/ν)^{1/2}이다.

```latex
\rho_{\mathbf k}=\frac{B_{\mathbf k}-\mu G s\,k^2\psi_{\mathbf k}}{Dk^2+\nu}\quad\Rightarrow\quad \rho^{\mathrm{tr}}_{\mathbf k}=-\frac{Gs}{T}\,\frac{k^2}{k^2+\ell_\nu^{-2}}\,\psi_{\mathbf k}
```

- kℓ\_ν ≫ 1이면 ρ ∝ −ψ\_e이다. 이동하는 입자의 볼츠만 분리이며 K → G에 해당한다.
- kℓ\_ν ≪ 1이면 ρ ∝ ω이다. 국소 결합이며 K → −κ′∇²에 해당한다. 긴 파장의 유효 결합은 ρ = (2gλ − μG s)ω/ν이며, 격자 항과 수송 항이 같은 꼴로 경쟁한다.
- 닫힌 시료에서 수송 항의 총합은 벽의 ℓ\_ν 층이 지운다.

4. ν = 0, B = 0(쌍 과정만)이면 평균장 정상해는 수송 속도와 무관하게 정확히 다음과 같다. 각 종의 흐름이 0이고 국소 생성과 소멸이 균형을 이루기 때문이다.

```latex
n_\pm(\mathbf r)=n_0\,e^{\mp G\psi_e/T},\qquad n_+n_-=n_0^2\ \ (\text{위치에 무관}),\qquad \frac{\bar n}{n_0}=\big\langle e^{-G\psi_e/T}\big\rangle\ \ge 1
```

소용돌이가 있는 흐름은 순 전하 없이 총 스커미온 밀도를 높인다. 균일 흐름에서는 밀도가 변하지 않았으므로(검증 (다)), 밀도를 바꾸는 것은 ψ\_e의 공간 변화, 곧 소용돌이도뿐이다.

*남는 가설.* λ = κ\_eff/k\_BT, 즉 저온 핵생성 편향이 고온 유사 에너지의 국소 결합과 같다는 가정은 전체 LLG(다음 5)에서 확인해야 한다. 여기서는 λ의 존재만 대칭으로 보장되고, 크기는 열린 문제이다.

**모형과 실제의 일치.** P\_Q의 정확성은 Thiele 방정식의 구조와 u\_eff의 발산 0만 쓴다. 따라서 스커미온 모양이나 크기에 무관하다. β = α이면 ψ\_e = 0이 되어 모든 효과가 사라진다는 것이 이 그림의 판별 기준이다.

## 5. 2차원 하이젠베르크의 열적 스커미온 쌍 통계

하이젠베르크에서는 모든 스커미온–반스커미온 쌍이 u\_eff에 의해 갈라진다. 그러나 로그 결합이 없으므로 해리는 열활성 과정이 아니고, 효과는 밀도가 아니라 상관과 가장자리에 나타난다.

**5.1 평형 기준.**

- BP 하한은 E ≥ 4πJS²|Q|이다. 같은 부호 다중 스커미온(정칙 해)은 상호작용이 없다.
- 반대 부호 쌍은 멀리서 ∼ Jλ₁λ₂ cos Δφ / R²의 쌍극자형 상호작용을 한다. 상대 위상에 의존하고 로그 항이 없다.
- 크기 분포는 재규격화 로그 보정을 빼면 대략 dλ/λ라 작은 스커미온이 지배한다. 그런데 바로 그 격자 척도에서만 Q가 바뀐다.
- 따라서 절대 개수 대신 ⟨Q⟩/χ\_t, 쌍 상관의 비대칭, 가장자리 분포처럼 비율로 된 양을 관측한다.

**5.2 쌍 구동 규칙.** 감쇠 텐서가 같으면 상대 구동은 G₁ − G₂ ∝ Q₁ − Q₂에 비례한다.

- 하이젠베르크 스커미온은 G = 4πQs가 Q로만 정해지므로, 스커미온–반스커미온 쌍은 항상 구동된다.
- 용이면 소용돌이에서 같은 핵 편극 쌍은 Q = ±1/2로 반대라 구동된다. 이것이 기존 결과이다.
- 반대 핵 편극 쌍은 Q = ±1인 메론 쌍, 즉 스커미온 하나이다. 통째로 Hall 운동만 하고 내부 구동이 없다.
- 정리하면 "전체 Q = 0인 쌍은 갈라지고, Q ≠ 0인 복합체는 실려 간다"이다. 기존 소용돌이 결과는 이 규칙의 용이면 극한이다.

**5.3 해리 길이.** 상대 확산 D\_r = 2μ\_r k\_BT와 상대 표류 v\_rel = 2μ\_r G|u\_eff|의 비에서 α와 감쇠 텐서가 빠진다.

```latex
\ell_u=\frac{D_r}{v_{\mathrm{rel}}}=\frac{k_BT}{G\,|u_{\mathrm{eff}}|}
```

2차원 확산은 재귀적이고, 전류는 계 크기 L 대신 적외 절단 ℓ\_u를 준다. 핵 거리 R₀에서 생성된 쌍의 탈출 확률과 자유 쌍의 소멸 속도 상수는 같은 로그를 가진다.

```latex
P_{\mathrm{esc}}=\frac{\ln(R_0/a)}{\ln(4\ell_u/a)-\gamma_E},\qquad k=\frac{2\pi D_r}{\ln(4\ell_u/a)-\gamma_E},\qquad n_f^2=\frac{\Gamma_n P_{\mathrm{esc}}}{k}=\frac{\Gamma_n\ln(R_0/a)}{2\pi D_r}
```

유도: 적중 확률 h를 h = e^{−x/2ℓ\_u} g로 바꾸면 g는 ∇²g = g/(4ℓ\_u²)를 따르고, 선도 해는 h ≈ e^{−x/2ℓ\_u} K₀(r/2ℓ\_u)/K₀(a/2ℓ\_u)이다. K₀(z) ≈ ln(2/z) − γ\_E가 분모의 상수 ln 4 − γ\_E ≈ 0.81을 준다. 소멸 속도 상수 k에도 같은 K₀(a/2ℓ\_u)가 들어가므로 n\_f에서는 상수까지 상쇄된다.

따라서 자유 스커미온 밀도는 선도 로그 차수에서 u\_eff에 무관하다. 성립 조건은 a ≪ ℓ\_u ≪ n^{−1/2}이다. 다체 계산에서는 이 조건 밖(ℓ\_u ≳ n^{−1/2}, 전류 없음)까지 포함해 ℓ\_u = 5–∞에서 ±3% 안에서 평평했다(6절 검증 기록 (다)).

**5.4 소용돌이와의 대비.**

|  | XY 소용돌이 | 하이젠베르크 스커미온 |
| --- | --- | --- |
| 쌍 결합 | 2πK ln r | ∼ λ²/R², 로그 없음 |
| 구동되는 쌍 | 같은 핵 편극 쌍 | 모든 S–anti-S 쌍 |
| 특성 길이 | r\* = 2πK/(G u\_eff), 에너지/힘 | ℓ\_u = k\_BT/(G u\_eff), 엔트로피/힘 |
| 자유 밀도 | n\_f ∝ \|G u\_eff\|^{πK/T} | 선도 로그 차수에서 u\_eff에 무관 |
| 전류가 드러나는 곳 | 밀도와 상관 길이 | 쌍 상관의 방향성과 가장자리 |

**5.5 크기 추정.** 박막의 스커미온당 G = 4πM\_s t/γ이다. M\_s = 1 MA/m, t = 1 nm, u\_eff ≈ 100 m/s, 300 K이면 ℓ\_u ≈ 0.6 nm이다. 실제 박막은 강하게 구동된 영역에 있고, 열적 선형 영역은 β ≈ α 근처나 작은 전류에서 열린다. 무차원 수 Π = G u\_eff a/k\_BT가 두 영역을 가른다.

**5.6 쌍 상관의 방향 비대칭 (정확한 두 물체 해).** 희박 기체(ℓ\_u ≪ n^{−1/2})에서 상대 좌표 r = r₊ − r₋의 쌍 밀도 c = n²g는 상대 표류 v\_rel = D\_r/ℓ\_u를 가진 표류–확산을 따른다. 쌍은 반지름 R₀의 고리에서 생기고 r = a에서 흡수된다. θ는 v\_rel = −2μ\_r G₊ ẑ×u\_eff에서 잰다. c = e^{ρ cos θ}φ (ρ = r/2ℓ\_u)로 두면 φ는 수정 헬름홀츠 방정식을 따르고, 모든 조화 m에서 흡수 조건을 맞춘 해는 다음과 같다.

```latex
g=\frac{e^{\rho\cos\theta}}{n^2}\Big[n^2e^{-\rho\cos\theta}+\frac{\Gamma}{2\pi D_r}\sum_m\epsilon_m(-1)^m I_m(z_0)\,F_m(\rho)\cos m\theta-\sum_m\epsilon_m(-1)^m\big(n^2+\gamma_m\big)\frac{I_m(z_a)}{K_m(z_a)}K_m(\rho)\cos m\theta\Big]
```

여기서 z₀ = R₀/2ℓ\_u, z\_a = a/2ℓ\_u, γ\_m = (Γ/2πD\_r)I\_m(z₀)K\_m(z₀)이다. F\_m은 ρ > z₀에서 I\_m(z₀)K\_m(ρ), ρ < z₀에서 K\_m(z₀)I\_m(ρ)이다. n²은 흡수 선속이 Γ와 같다는 조건으로 정해지며, 얻는 데 Wronskian I\_mK\_m′ − I\_m′K\_m = −1/ρ을 쓴다.

```latex
n^2=\frac{\Gamma/2\pi D_r-\sum_m\epsilon_m(-1)^m R_m\gamma_m}{\sum_m\epsilon_m(-1)^m R_m},\qquad R_m=\frac{I_m(z_a)}{K_m(z_a)}\ \ \Big(\approx\frac{\Gamma}{2\pi D_r}\big[K_0(z_a)-I_0(z_0)K_0(z_0)\big]\Big)
```

물리적 그림은 두 꼬리의 경쟁이다.

- 비쌍생 쌍: 흡수 핵이 하류로 e^{ρcosθ}K₀(ρ) 꼴의 결손 꼬리(그림자)를 만든다.
- 쌍생 쌍: R₀에서 태어난 쌍이 하류로 밀려 같은 꼴의 과잉 꼬리를 만든다.
- n²이 위의 값일 때 두 꼬리는 먼 거리에서 선도 차수까지 상쇄된다. n\_f가 전류에 무관한 것과 같은 등식이다.
- 남는 비대칭은 핵 근처(r ≲ R₀ + 2ℓ\_u)의 그림자이고 부호는 음이다. 즉 r̂₊₋는 v\_rel의 반대쪽(상류)으로 치우친다.
- 크기는 R₀/ℓ\_u와 a/ℓ\_u로 정해진다. 코사인 성분 g₁의 최대값은 R₀/ℓ\_u = 0.2, 1, 2에서 −0.02, −0.13, −0.17이다.

**모형과 실제의 일치.** ℓ\_u는 Thiele 방정식의 표류–확산 비만 쓰므로 α와 감쇠 텐서에 무관하다. 실험에서 알려진 스커미온 Hall 각이 β = α에서 사라진다는 사실은 ℓ\_u → ∞와 같은 내용이다.

- 성립 조건 ℓ\_u ≪ n^{−1/2}를 벗어난 ℓ\_u = 150과 ∞에서도 평평하다. 이 영역에서는 P\_esc와 k의 로그가 모두 입자 간격에서 잘리므로, 같은 절단으로 다시 상쇄된다고 해석한다. 전류가 밀도에 영향을 주지 않는다는 결론은 5.3절의 조건보다 넓게 성립한다.
- 기체 속 쌍의 탈출 비율은 ℓ\_u ≪ 간격일 때 단일 쌍 공식과 맞는다(ℓ\_u = 5: 0.417 대 0.422, R₀ = 8: 0.588 대 0.591). ℓ\_u ≳ 간격에서는 제3 입자가 짝을 먼저 소멸시키므로 단일 쌍 값보다 크다.
- 오차: 블록 평균 오차는 ±1%로 나오지만, 시드에 따른 분산(같은 ℓ\_u = 15에서 1.033 대 1.005)으로 보면 실제 불확도는 ±2.5% 정도이다. 위 결론은 이 불확도 안에서 성립한다.

*(라) 쌍 상관 g₊₋(r, θ)의 방향 비대칭.* (다)와 같은 다체 기체에서, 모든 +− 쌍의 상대 벡터를 스냅샷마다 (r, θ) 히스토그램으로 모았다. θ는 상대 표류 방향에서 잰다. Γ = 1.1×10⁻⁷, L = 1500(입자 간격 ≈ 90), 시간 1.6×10⁵(ℓ\_u = 15는 2.9×10⁵)을 썼고, 오차는 10개 블록 평균에서 구했다. 이론은 5.6절의 정확한 두 물체 해이고 맞춤 매개변수는 없다. ⟨cos θ⟩는 r < 4ℓ\_u인 쌍에 대한 평균이다.
