# 계산 의뢰서: 비상반 구동 아래 스커미온 핵생성 편향 (분기 논문 A, 단계 B)

Oct 22, 2026 · Changyeon Won (Kyung Hee University)

## 1. 목적과 검증할 가설

이 의뢰의 목표는 전단 흐름 형태의 비상반 구동이 저온 스커미온 핵생성률을 국소 소용돌이도 ω의 부호에 따라 편향시키는지 측정하고, 그 계수 c를 구하는 것이다. 이론의 배경과 기존 검증은 [분기 논문 A 구조안](branch_A_structure.md)의 2.6, 3.5, 4.6절과 6절 검증 기록에 있다. 이 의뢰서만 읽고도 작업할 수 있도록 필요한 식과 규약은 모두 여기에 다시 적는다.

**대칭이 정한 꼴 (검증 대상).** 사건률의 로그 편향은 유사스칼라이고 세차 부호에 홀이어야 한다. 흐름 v(r)에 선형인 국소 유사스칼라는 ω = ẑ·∇×v 하나뿐이다.

```latex
\ln\frac{\Gamma_Q(\omega)}{\Gamma_Q(0)}=c\,Q\,\omega+O(\omega^2),\qquad c\propto\frac{\beta-\alpha}{\alpha}\quad(\text{전류 구동}),\qquad u_{\mathrm{eff}}=\frac{\beta-\alpha}{\alpha}u
```

**확인할 것 (우선순위 순).**

1. 편향이 있는가: ω > 0 영역과 ω < 0 영역의 핵생성률 비 R ≠ 1인가.
2. 대칭이 요구하는 의존성: ln R이 u₀에 선형이고, u₀ → −u₀에서 부호가 바뀌며, β = α에서 0이고, (β − α)/α에 비례하는가.
3. 균일 전류(ω = 0)는 편향을 만들지 않는가. 계면 DMI에는 (v, ẑ) 거울이 남으므로 모든 차수에서 0이어야 한다.
4. 계수 c가 T, D, B에 어떻게 의존하는가. 가설은 c ≈ κ\_eff Q\_s/k\_BT(유사 에너지 결합 × 안장점 전하)이고, D에는 약하게만 의존하는 것이다. 결과가 이 가설과 다르면 그대로 보고한다.

판별의 핵심은 2번이다. 예상과 다른 결과가 나오면, 구현 오류인지 물리인지는 β = α 대조군으로 가른다. 모형을 바꿔 원하는 결과를 만들지 말고, 얻은 그대로 보고한다.

## 2. 모형, 규약, 구동 구현

정사각 격자(격자 상수 a = 1), 양쪽 주기 경계, |S\_i| = 1이다. 단위는 J = γ = μ = k\_B = 1로 둔다.

**에너지.** 계면(Néel) DMI와 면에 수직인 자기장, 선택적 수직 이방성을 쓴다.

```latex
E=-J\sum_{\langle ij\rangle}\mathbf S_i\cdot\mathbf S_j-\sum_{\langle ij\rangle}\mathbf D_{ij}\cdot(\mathbf S_i\times\mathbf S_j)-B\sum_i S_i^z-K\sum_i(S_i^z)^2,\qquad \mathbf D_{ij}=D\,(\hat z\times\hat e_{ij})
```

**동역학 (Zhang–Li 토크를 포함한 Gilbert 꼴).** 전류는 속도 단위 벡터장 u(r)로 넣는다. 비단열 계수는 β이다.

```latex
\dot{\mathbf S}_i=-\mathbf S_i\times(\mathbf H_i+\mathbf h_i^{\mathrm{th}})+\alpha\,\mathbf S_i\times\dot{\mathbf S}_i+\boldsymbol\tau_i,\qquad \boldsymbol\tau_i=-P_i(\mathbf u\cdot\nabla)\mathbf S_i+\beta\,\mathbf S_i\times(\mathbf u\cdot\nabla)\mathbf S_i
```

- H\_i = −∂E/∂S\_i이고, P\_i = 1 − S\_iS\_i^T는 접평면 사영이다.
- (u·∇)S\_i는 중앙 차분으로 쓴다: u\_x(S\_{i+x̂} − S\_{i−x̂})/2 + u\_y(S\_{i+ŷ} − S\_{i−ŷ})/2. u는 결합 중점이 아니라 자리 i의 값을 쓴다.
- 이 항은 구조안 2.4절의 비상반 결합과 같다. 단열항은 DL 채널의 δJ, 비단열항은 FL 채널의 βδJ이다. 중요한 불변량은 u\_eff = (β − α)u/α이다.

**LL 꼴 (적분에 쓸 양함수 형태).** τ가 접평면에 있으므로 다음을 쓴다. h^th는 두 항의 H에 모두 더한다.

```latex
(1+\alpha^2)\dot{\mathbf S}=-\mathbf S\times\mathbf H-\alpha\,\mathbf S\times(\mathbf S\times\mathbf H)+\boldsymbol\tau+\alpha\,\mathbf S\times\boldsymbol\tau,\qquad \langle h^{\mathrm{th}}_{i,a}(t)h^{\mathrm{th}}_{j,b}(t')\rangle=2\alpha k_BT\,\delta_{ij}\delta_{ab}\delta(t-t')
```

**전단 흐름.** 주 구동은 정현 전단이다. 평균 전류가 0이므로 스커미온의 알짜 표류가 없고, 한 시료 안에 ±ω 영역이 함께 생긴다.

```latex
\mathbf u(y)=u_0\sin\!\Big(\frac{2\pi y}{L_y}\Big)\hat x,\qquad \omega(y)=-\partial_yu_x=-\frac{2\pi u_0}{L_y}\cos\!\Big(\frac{2\pi y}{L_y}\Big)
```

u₀ > 0이면 L\_y/4 < y < 3L\_y/4에서 ω > 0이다. 대조군으로는 균일 전류 u = u₀x̂(ω = 0)를 쓴다.

**규약 확인 사항.** 적분기의 부호 규약(Ṡ = −S×H, γ > 0)을 바꾸지 말 것. 서로 다른 규약을 쓰고 싶다면 보고서에 변환식을 적는다. 선호되는 스커미온의 Q 부호(B > 0일 때 중심이 −z를 향하는 Néel 스커미온)는 직접 계산해서 기록한다.

## 3. 적분과 측정 방법

**적분기.** Stratonovich Heun(예측–수정)을 쓰고, 매 단계 끝에 |S| = 1로 재규격화한다. 예측 단계에서도 재규격화한다. 두 단계가 같은 잡음 난수를 쓴다. 시간 간격은 dt ≤ 0.02/J에서 시작하고, 편향 검사를 위해 주요 결과 하나를 dt/2로 다시 계산한다. GPU(JAX, CuPy, Numba-CUDA 중 하나)를 권장한다. 복제본은 배치 차원으로 동시에 돌린다.

**위상 전하.** Berg–Lüscher 입체각을 쓴다. plaquette (i, i+x̂, i+x̂+ŷ, i+ŷ)를 대각선으로 나눈 두 삼각형의 입체각 합을 q\_p로 한다.

```latex
\Omega(\mathbf a,\mathbf b,\mathbf c)=2\,\mathrm{atan2}\big(\mathbf a\cdot(\mathbf b\times\mathbf c),\ 1+\mathbf a\cdot\mathbf b+\mathbf b\cdot\mathbf c+\mathbf c\cdot\mathbf a\big),\qquad Q=\frac{1}{4\pi}\sum_{\triangle}\Omega
```

한 방향 대각선 분할의 Q는 항상 정수이므로 사건 검출에는 이것을 쓴다. 단, 이 Q는 거울에 대해 배위별로 홀이 아니다. 대칭 검사(구조안 2.6절)에 쓰는 평균량은 두 대각선 분할의 평균으로 계산한다.

**사건 검출.**

1. 간격 Δt\_s(기본 0.25/J)마다 복제본별로 q\_p 지도와 전체 Q를 기록한다.
2. 전체 Q가 바뀌면, 3×3 plaquette 창으로 거친 지도의 변화 Δq\_w가 가장 큰 창을 사건 위치로 잡는다. Δq\_w ≈ ±1이어야 한다. 그렇지 않으면(여러 사건이 겹침) 플래그를 달아 따로 센다.
3. ΔQ = Q\_fav(선호 부호)는 핵생성, ΔQ = −Q\_fav는 붕괴로 분류한다. 반대 부호 사건과 동시 쌍 사건(ΔQ = 0)도 별도로 기록한다.
4. Δt\_s가 너무 길면 사건이 상쇄되어 놓칠 수 있다. Δt\_s를 절반으로 줄여 사건 수가 5% 이상 달라지면 Δt\_s를 줄인다.

**비율의 정의.**

- 핵생성률 Γ\_nuc(y): y 띠별 사건 수 / (띠 넓이 × 시간 × 복제본 수). 배경 상태가 바뀜 수 있으므로, 스커미온이 차지한 넓이(반지름 2R 안)는 넓이에서 뺀다.
- 붕괴율 ν(y): 띠별 붕괴 사건 수 / (그 띠에 있던 스커미온 수의 시간 적분). 스커미온 밀도는 Thiele 수송 때문에 불균일할 수 있으므로(구조안 4.2, 4.6절) 반드시 개체당으로 정규화한다.
- ω(y)에 대한 적합: ln Γ(y) = ln Γ₀ + s·ω(y). y를 16개 띠로 나누고 푸아송 가중 최소제곱을 쓴다. 핵생성의 기울기 s\_nuc = cQ\_fav, 붕괴의 기울기 s\_col를 따로 보고한다.
- 간단한 요약량: R = Γ(ω > 0 절반)/Γ(ω < 0 절반). 오차는 δln R ≈ (1/N₊ + 1/N₋)^{1/2}이다.

**부가 기록.** 스커미온 중심 궤적(국소 q의 무게중심)을 추적해 표류 속도 v(y)와 y 방향 밀도 분포를 함께 기록한다. 이것은 Thiele 예측(아래 V4)과 흐름 함수 볼츠만 분포(구조안 4.2절)의 교차 검증에 쓴다.

## 4. 사전 검증: 반드시 통과해야 할 기준

과제 1을 시작하기 전에 아래 네 가지를 통과해야 한다. 하나라도 실패하면 과제 1로 넘어가지 말고 원인과 함께 보고한다.

| 번호 | 검사 | 조건 | 기준 값 | 허용 오차 |
| --- | --- | --- | --- | --- |
| V1 | 요동–소산 정규화 | J = D = K = 0, B = 0.5, T = 0.5, u = 0 | ⟨S\_z⟩ = coth(B/T) − T/B = 0.3130 | 1% |
| V2 | 평형 분포와 DMI 부호 | J = 1, D = 0.3, B = 0.12, T = 0.4, u = 0 | 독립 Metropolis MC의 자리당 에너지와 ⟨S\_z⟩ | 0.5% |
| V3 | Galilei 불변성 | 고립 스커미온, T = 0, α = β = 0.1, 균일 u = 0.02x̂ | v = u, Hall 각 0 | 1% |
| V4 | Thiele 속도 | 같은 스커미온, α = 0.1, β = 0과 0.2 | 아래 식 | 5% |

V4의 기준식은 Gẑ×(v − u) + 𝒟(αv − βu) = 0의 해이다. 구조안 3단계 검증에서 쓴 것과 같다.

```latex
\mathbf v=\frac{\beta}{\alpha}\mathbf u-\frac{G^2}{\alpha^2\mathcal D^2+G^2}\,\mathbf u_{\mathrm{eff}}-\frac{\alpha\mathcal D G}{\alpha^2\mathcal D^2+G^2}\,\hat z\times\mathbf u_{\mathrm{eff}},\qquad G=4\pi Q,\quad \mathcal D=\sum_i\big(\partial_x\mathbf S_i\big)^2
```

- 𝒟는 완화된 스커미온 모양에서 중앙 차분으로 구한다.
- G의 부호는 규약에 따라 달라질 수 있다. β = 0 경우의 Hall 방향으로 부호를 정하고 보고한다. 크기와 β 의존성이 검사 대상이다.
- V3은 β = α에서 u\_eff = 0이 되는 성질을 확인한다. 이것이 과제 1의 β = α 대조군이 의미를 갖기 위한 전제이다.

**추가 확인.** 구동 없이(u = 0) 과제 1의 온도에서 핵생성률의 y 의존성이 없어야 한다(두 절반의 ln R이 0과 2σ 안에서 일치). 이것은 사건 검출과 구간 할당에 편향이 없음을 보인다.

## 5. 과제 1 (주): 핵생성 편향 c 측정

세 단계로 진행한다. 각 단계가 끝나면 중간 보고를 남긴다.

**1A. 보정 (모형과 온도 선택).**

1. 시작값은 (D, B, K) = (0.3, 0.12, 0)이다. T = 0에서 균일 상태가 안정하고 고립 스커미온이 준안정한지(반지름 2–6a) 확인한다. 아니면 B를 0.08–0.2 안에서 조정한다.
2. 구동 없이 온도 사다리(예: T = 0.25–0.6)에서 Γ₀(T)를 잰다. ln Γ₀ 대 1/T로 장벽 ΔE\_b를 구해 보고한다.
3. 다음 세 조건을 만족하는 T⋆를 고른다. (i) 계산 예산 안에서 점마다 핵생성 사건이 2000개 이상, (ii) 스커미온이 희박(평균 간격 ≳ 10 × 지름), (iii) 겹침 플래그가 사건의 10% 미만.

**1B. 주 계산 (T = T⋆).** L\_x = L\_y = 64–128, 복제본 8–32개. u₀는 먼저 시험 계산으로 ln R이 측정 가능하면서(|ln R| ≳ 0.1) u₀에 선형인 범위를 찾는다. 예상 범위는 0.02–0.1이며, 전류 구동 스핀파 불안정성(구조안 5.4절의 u⋆) 아래에 있어야 한다.

| 점 | α | β | 구동 | 목적 |
| --- | --- | --- | --- | --- |
| P1 | 0.1 | 0 | 전단 +u₀ | 주 측정 |
| P2 | 0.1 | 0 | 전단 −u₀ | 부호 반전 |
| P3 | 0.1 | 0 | 전단 +u₀/2 | 선형성 |
| P4 | 0.1 | 0.2 | 전단 +u₀ | (β − α)/α = +1, 부호 반전 예측 |
| P5 | 0.1 | 0.1 | 전단 +u₀ | β = α 대조군: 편향 0 |
| P6 | 0.1 | 0 | 균일 u₀x̂ | ω = 0 대조군: 편향 0 |
| P7 | 0.1 | 0 | u = 0 | 무구동 기준 |
| P8 | 0.3 | 0 | 전단 +u₀ | α 의존성 ((β − α)/α = −1로 P1과 같음) |
| P9 | 0.3 | 0.6 | 전단 +u₀ | (β − α)/α = +1, P4와 비교 |

점마다 핵생성과 붕괴의 기울기 s\_nuc, s\_col을 오차와 함께 구한다. 예측은 다음과 같다.

- P2는 P1과 부호가 반대이고, P3은 P1의 절반이다.
- P4는 P1과 부호가 반대이고 크기가 같다. β 의존성이 (β − α)를 통해서만 들어오는지를 본다.
- P5, P6, P7은 2σ 안에서 0이다.
- P8과 P9는 α가 달라도 u\_eff가 같으면 같은 편향을 주는지를 본다. 다르다면 그 비율을 보고한다. 유사 에너지는 1/α에 의존할 수 있으므로, 어느 쪽이든 의미 있는 결과이다.
- 국소 상세균형(유사 에너지) 그림이 맞다면 s\_col ≈ −s\_nuc이다. 이 비율을 반드시 보고한다.

**1C. 의존성 (시간이 남으면).** P1과 P4를 다음 조건에서 반복한다.

- T⋆의 위아래 두 온도: c ∝ 1/T인지 본다. cT를 표로 낸다.
- D = 0.2, 0.4 (B/D²를 고정): c가 D에 약하게만 의존하는지 본다.
- 전단 주기 L\_y를 바꿔 ω와 u₀를 따로 바꾼다: 편향이 u가 아니라 ω를 따르는지 확인한다. 이것이 선택 규칙의 가장 직접적인 시험이다.

이론과의 수치 비교(κ\_eff, Q\_s)는 의뢰자가 한다. 계산 쪽에서는 c, cT, s\_col/s\_nuc, ΔE\_b, 스커미온 반지름과 𝒟를 보고하면 충분하다.

## 6. 과제 2, 3 (선택)

과제 1이 끝난 뒤 예산이 남으면 과제 2를 먼저 한다. 같은 코드에서 DMI와 구동만 바꾼다.

**과제 2: 키랄 점군에서 균일 흐름의 방향 의존성.** 대칭 논증의 예측은 다음과 같다. 거울이 없는 D₂ 점군에서는 균일 흐름도 v² 차수에서 편향을 만들 수 있다. D₄에서는 이 항이 금지되어 v⁴ sin 4θ부터 나온다.

- 모형: 벼크형(Bloch) DMI. x 결합은 D\_ij = D\_x ê\_ij, y 결합은 D\_ij = D\_y ê\_ij로 둔다. D\_x = D\_y이면 D₄, D\_x ≠ D\_y이면 D₂이다.
- 구동: 균일 u = u₀(cos θ, sin θ), θ = ±π/8, ±π/4. α = 0.1, β = 0.
- 측정: 같은 |u₀|에서 ln\[Γ(θ)/Γ(−θ)\]. 예측은 D₂에서 ∝ u₀² sin 2θ, D₄에서는 이 차수에서 0이다. u₀를 두 값 써서 u₀² 스케일링을 확인한다.
- 주의: 여기서는 u₀가 커야 하므로 스핀파 불안정성 문턱을 먼저 확인한다. D\_y/D\_x = 1, 0.5 두 경우면 충분하다.

**과제 3: 순수 하이젠베르크의 열적 위상 밀도 (탐색).** 구조안 검증 (다), (라)의 입자 모형 예측을 전체 LLG에서 확인하는 것이 목적이다.

- 모형: D = B = K = 0, 균일 u, β ≠ α. 무차원 수 Π = G u\_eff a/k\_BT ≲ 0.1을 지킨다.

## 8. 추가 의뢰 (단계 B′): β = α 잔여와 L 의존성의 판별

단계 B 보고서(2026-10-22)를 검토한 결과, β = α 잔여 s\_adv는 물리적 효과로 판단한다. 의뢰서의 전제 c ∝ (β − α)/α는 아래처럼 고친다. 이 절의 측정은 그 기작을 확인하거나 반증하는 것이 목적이다.

```latex
s_{\mathrm{nuc}}=s_{\mathrm{rot}}(D,\alpha,T)+k\,\frac{\beta-\alpha}{\alpha}
```

**기작 (의뢰자 해석).** β = α이면 동역학은 D\_tS = −S×h + αS×D\_tS이고 D\_t = ∂\_t + (u·∇)이다. 국소적으로 흐름은 변형과 회전 Ω = ω/2로 나뉜다. 변형은 대칭 무대각 텐서라서 D4 대칭에서 스칼라 비율과 1차로 결합하지 못한다. 회전에 대해서는 다음 항등식이 성립한다(ω = ∂\_x u\_y − ∂\_y u\_x, 연속 극한).

```latex
(\mathbf u\cdot\nabla)\mathbf S=-\Omega\,\mathcal G\mathbf S+\Omega\,\hat z\times\mathbf S,\qquad \mathcal G\mathbf S=\hat z\times\mathbf S-\partial_\varphi\mathbf S
```

𝒢는 공간과 스핀을 함께 돌리는 생성자이고, 계면 DMI 에너지는 이 결합 회전에 불변이다. 따라서 𝒢 부분은 좌표계로 지울 수 있다. 남는 것은 스핀만 z축 둘레로 도는 항이고, LL 꼴로는 감쇠 짝이 없는 세차장 −Ωẑ가 된다.

```latex
\dot{\mathbf S}=-\mathbf S\times(\mathbf h-\Omega\hat z)-\alpha\,\mathbf S\times(\mathbf S\times\mathbf h)
```

E가 스핀만의 z 회전에 불변이면(교환, B\_z, K S\_z²만 있으면) 이 항도 회전 좌표계로 정확히 지워진다. DMI는 스핀을 격자에 묶으므로 지워지지 않는다. 그래서 s\_rot은 DMI가 있어야 생긴다. 균일 u(P6)는 Ω = 0이므로 편향이 없다는 결과와도 맞는다.

**크기 예측 (2026-10-23 추가).** 의뢰자 계산(구조안 2.8절)에 따르면 αT ≪ J인 약감쇠 영역에서는 세차장 −Ωẑ가 진짜 Zeeman 장 B\_eff = −ω/2처럼 작용한다. 온도는 (1 − Ωr)만큼 재규격화되고, 저온 강자성 상태에서 r ≈ −1/(4J + B)이다. 단계 B(αT = 0.05)는 이 영역에 있으므로 다음을 예측한다.

```latex
s_{\mathrm{rot}}=\frac{1}{2T}\Big[\frac{\partial\Delta E_b}{\partial B}-\frac{\Delta E_b}{4J+B}\Big]
```

이 값은 α에 무관하고 1/T에 비례하며, 장이 고른 전하의 핵생성을 돕는 부호를 갖는다. 측정된 s\_rot = 14–20이 되려면 ∂ΔE\_b/∂B ≈ 15–21이어야 한다. D = 0이면 효과는 정확히 0이다. 강감쇠 영역(αT ≫ J)에서는 대신 B\_eff = −ω/(8α²)가 된다.

**L = 128 점에 대한 가설.** 단일 정현 흐름에서는 ω(y)와 흐름 함수 ψ(y)가 둘 다 cos(2πy/L)에 비례해서, ω에 대한 기울기만으로는 국소 ω 응답과 ψ(또는 |u|L) 응답을 가를 수 없다. ω를 고정하고 L과 u₀를 2배로 하면 ψ 진폭은 4배가 된다. β = α에서는 u\_eff = 0이므로 L = 128 값(15 ± 9)이 L = 64 값(20 ± 4)과 같다는 점은 이 가설과 맞는다. 다만 보고서 4절(수송 편향이 보이지 않고, 밀도 불균일이 국소 비율로 설명됨)은 ψ가 수송을 통해 작용한다는 경로에 불리하다. 그래서 반복 측정과 흐름 모양 분리를 먼저 한다.

## 9. 추가 의뢰 (단계 B″): 회전 항의 크기와 남은 불일치

단계 B′(`REPORT_B2.md`)로 회전 기작은 확정되었다(P10). 편향은 국소 ω 응답이고(P14의 a\_ψ = 0), L 의존은 없다(P13). 이번 의뢰는 회전 항의 크기를 정량으로 검증하고, 남은 세 가지 불일치를 가리는 것이 목적이다.

**고친 예측.** αT ≪ J인 약감쇠 영역에서는 정상 측도가 (B, T) → (B − ω/2, T(1 + ωr/2))의 평형과 같다(구조안 2.8절). 따라서 장벽만이 아니라 비율 전체가 이동한다.

```latex
s_{\mathrm{rot}}^{\mathrm{pred}}=-\frac12\frac{\partial\ln\Gamma_0}{\partial B}+\frac{rT}{2}\frac{\partial\ln\Gamma_0}{\partial T},\qquad r\approx-\frac{1}{4J+B}
```

## 10. 추가 의뢰 (단계 B‴): 측도와 운동학의 분리 (재분석만)

단계 B″에서 회전 항은 약감쇠 Zeeman 등가 예측의 F = 0.74 ± 0.11배였고, F는 α와 D에 무관했다. 등가성은 정상 측도에 대한 진술이다. 핵생성률은 측도와 안장점을 지나는 흐름을 함께 포함한다. 이번 의뢰는 F < 1이 측도에서 오는지 운동학에서 오는지를 가르는 것이다. **새 계산은 필요 없고, 기존 자료의 재분석만 한다.**

**원리.** 국소 정상 상태에서 확립된 스커미온 밀도는 n = Γ\_nuc/ν이다(ν는 붕괴율). 따라서 ln n의 기울기 s\_nuc − s\_col은 안장점이 아니라 두 상태의 개체 수 비, 즉 측도만 반영한다. 측도가 정확히 등가이면 다음이 성립해야 한다.

```latex
(s_{\mathrm{nuc}}-s_{\mathrm{col}})^{\mathrm{pred}}=-\frac12\frac{\partial\ln n_0}{\partial B}+\frac{rT}{2}\frac{\partial\ln n_0}{\partial T},\qquad \ln n_0=\ln\Gamma_{\mathrm{nuc},0}-\ln\nu_0,\quad r=-\frac{1}{4J+B}
```

반대로 s\_nuc + s\_col은 안장점의 이동이며, 운동학 효과는 여기에 나타난다.

**해야 할 것.**

1. **무구동 기준 (P16, P15, P17 자료).** ∂ln ν₀/∂B와 ∂ln ν₀/∂T를 P16과 같은 쌍 비교 잭나이프로 구한다. 그리고 ∂ln n₀/∂B, ∂ln n₀/∂T와 위 예측값을 보고한다. 밀도를 직접 재는 방법(확립된 스커미온 수의 시간 평균 / 넓이)으로도 구해 두 값을 비교한다.
2. **구동 자료.** 회전 구동(P10, P10b, P18 합계의 반대칭 부분), β = α 전단(P5 묶음), α 계열(P19 회전 구동 α = 0.025, 0.05, 0.1)에서 s\_nuc − s\_col과 s\_nuc + s\_col을 보고한다. ω 띠별 스커미온 밀도의 기울기 d ln n/dω도 직접 보고한다.
3. **비교.** 두 비를 보고한다. F\_pop = (s\_nuc − s\_col)/(s\_nuc − s\_col)^pred와 F\_sad = (s\_nuc + s\_col)/(s\_nuc + s\_col)^pred이다. 뒤의 예측은 진짜 장의 −½∂(ln Γ\_nuc + ln ν)/∂B + (rT/2)∂(…)/∂T로 구한다. 가능하면 D = 0.2, 0.4(P11, P17)에서도 같은 비를 구한다.

**판정.**

- F\_pop이 1과 2σ 안에서 일치하고 F\_sad가 1보다 작으면, 측도는 정확히 등가이고 F ≈ 0.74는 운동학 효과로 보고한다.
- F\_pop ≈ F ≈ 0.74이면 측도 자체가 줄어든 것으로 보고한다. 이때는 2.8절의 껍질 축약(ρ = f(E′))이 저온에서 성립하지 않는다는 뜻이다.
- 두 경우 모두 τ\_c = 5, 10, 20의 값을 함께 적는다. 붕괴 기울기는 확립 정의(나이 ≥ τ\_c)에 민감하므로, 생존 보정 기울기 s\_nuc + ντ\_c s\_col도 참고로 적는다.

**주의.** ω 띠별 밀도는 수송에도 영향을 받을 수 있다. 단계 B에서 v\_y는 잡음 수준이었고 확립된 스커미온 수명(≈ 17)이 짧아 국소적이어야 하지만, 회전 구동(u = 0)과 전단의 값을 따로 적어 확인한다. 붕괴 통계가 부족해 F\_pop의 오차가 0.2를 넘으면, P16의 세 B를 t = 16000으로 늘리는 것만 허용한다.

**산출물.** `stageB/REPORT_B4.md`와 `results/b4_summary.json`을 낸다. 예상 작업량은 분석 스크립트 수준이다.

## 11. 추가 의뢰 (단계 C): F\_pop의 온도 의존

단계 B‴에서 F < 1은 운동학이 아니라 정상 측도에서 왔다(F\_pop = 0.78 ± 0.10). 의뢰자의 해석은 "저온에서 E′ = E + ΩM 껍질 위의 혼합이 불완전하다"이다. 이 해석이라면 온도가 오를수록 비조화 혼합이 커져 F\_pop이 1로 다가가야 한다. 고온(T = 2, D = 1)에서는 ⟨q⟩ 기준 F = 1.02–1.14였다. 이번 의뢰는 F\_pop(T)를 직접 재는 것이다.

**측정점.** D = 0.3, B = 0.12, α = β = 0.1, L = 64, τ\_c = 10, 분석은 단계 B‴와 같다. 구동은 회전만(u = 0, D\_t = ∂\_t ± (ω/2)ẑ×, P10/P10b형)으로 하고 반대칭 부분을 쓴다.

T = 0.5는 기존 자료(F\_pop = 0.78 ± 0.10)를 쓴다. ∂ln n₀/∂T는 이웃 온도 점의 무구동 자료(B = 0.12)로 중앙차분한다. 양 끝은 한쪽 차분을 쓰거나, T = 0.40과 0.75 무구동 점을 더한다.

**보고할 것.** 각 T에서 다음 양을 보고한다.

- F\_nuc(= s\_nuc/s\_nuc^pred)와 F\_sad를 참고로 적는다.
- 열적 자화 결손 Δ⟨M⟩\_T = T∂ln n₀/∂B를 적는다. T = 0 이완값 ΔM₀ = −67.7과 비교하기 위해서다.
- τ\_c = 5, 20 값은 표로만 적는다.

**판정.**

- F\_pop이 T에 대해 증가하면(기울기가 0과 2σ 이상 다르고, C4에서 1과 2σ 안) 불완전 혼합 해석을 지지한다고 보고한다.
- F\_pop이 T에 무관하게 약 0.75이면, 장과 무관한 다른 상쇄 기작이 있다고 보고한다. r 항은 예측의 약 5%(−1.5/28.8)라서 r 추정의 오차로는 25% 감소를 설명할 수 없다.
