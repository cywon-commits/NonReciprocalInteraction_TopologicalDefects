## 2. 계산과 의뢰서와 다른 점

- **통계:** 의뢰서 목표(점마다 회전 구동 핵생성 4000건)는 모두 넘었다(0.45: 4140, 0.70: 5969). 그러나 T가 오르면 예측 신호가 44 → 10으로 줄어
  한 쌍(±ω)으로는 0.55, 0.60에서 F_pop 오차가 0.28–0.35였다. 그래서 0.55, 0.60에 ±ω 씨드 쌍 3개씩을 더했다(각 T에서 8개 계산, 핵생성 21739, 25962건).
  의뢰서에 없는 추가 계산이다.
- **희박 조건:** 0.55에서 간격 50a(경계), 0.60에서 35a, 0.70에서 21a로 의뢰서 기준(≈ 51a)을 0.60 이상에서 만족하지 못한다. L = 64는 그대로 두었다.
- **확립 정의:** 확립된 스커미온 수명(B = 0.11 무구동 기준 1/ν)은 0.45: 34, 0.55: 12, 0.60: 7.2, 0.70: 2.6이다. τ_c = 10은 0.60 이상에서 수명보다 길다.
  0.60의 τ_c = 5 값(0.75 ± 0.15)도 같은 결론을 준다.
- **ΔM_T:** T = 0.45–0.70에서 −41 → −14로 |ΔM_T|가 T와 함께 줄어든다. T = 0 이완값 −67.7의 0.61배(0.45)에서 0.20배(0.70)이다.
