## 1. P16: 예측값 갱신

  잭나이프로 미분을 구했다. 핵생성 3532, 1861, 1134건.
- ∂ln Γ₀/∂B: 중앙(±0.01) −57.5 ± 2.3, 아래 구간 −65.1 ± 4.1, 위 구간 −50.0 ± 4.4. 곡률이 뚜렷해 P15(±0.02)의 값(−57.8)은
  우연히 같았다.
- ∂ln Γ₀/∂T = 24.5 ± 0.6 (P15의 B = 0.12 아레니우스 자료, T = 0.45와 0.55의 중앙차분).

- 측정 20.1 ± 4.4(β = α 전단 묶음), P18 반대칭 20.2 ± 4.2, 합 20.2 ± 3.0 → **비 0.74 ± 0.11**.

## 3. P19: α 의존 (β = α)

| α | 전단 (P5형) | 회전 구동 (P10형) |
|---|---|---|
| 0.025 | +11.0 ± 7.9 (추가 점) | +17.8 ± 7.5 (추가, 비교용) |
| 0.05 | +0.7 ± 6.0 (P19 + P12) | +14.9 ± 7.2 |
| 0.1 | +20.1 ± 4.4 | +20.7 ± 6.1 |
| 0.2 / 0.3 | +18.0 ± 11.8 / +9.7 ± 12.7 | — |

- 규칙("α = 0.05가 다시 0 근처면 새 효과로 보고하고 α = 0.025를 추가")에 따라 α = 0.05 전단을 2배 통계로 다시 쟀고
  다시 0 근처(+2.9 ± 7.3)였으므로 α = 0.025를 추가했다. α = 0.025는 0과 1.4σ, 20과 1.2σ로 0 근처가 아니다.
  같은 α의 회전 구동은 0.025와 0.05 모두 15–18이다. 따라서 **α = 0.05 전단 값은 통계적 요동으로 처리**한다.
- 회전 구동 세 점의 가중평균은 +18.2 ± 3.9로, α에 무관하다는 약감쇠 예측과 맞는다(비 0.67 ± 0.14).
- 회전 구동을 추가한 것은 의뢰서에 없는 비교다. 전단과 회전 구동은 β = α에서 같은 회전 항을 갖고, 전단에는 변형률 성분이 더 있다.
  α ≤ 0.05에서 전단이 회전 구동보다 평균 12 ± 7 작다(1.7σ) — 유의하지 않다.

## 4. P20: FL 항의 파장 의존

- 단일 정현 전단, k = 6π/L (주기 21.3a), u₀ = 0.04/3 (ω_max가 P1과 같음), β = 0과 β = α, 각각 씨드 2개 × t = 16000 (핵생성 8156, 7702건).
- **띠 나눔:** 의뢰서는 띠를 3배(48개)로 늘리라고 했지만, 그러면 띠 폭이 1.33a로 같은 문단의 조건("띠 폭 > 스커미온 지름 ≈ 5a")과 충돌하고
  L = 64를 나누지 못한다. 단계 B와 같은 16띠(폭 4a)를 쓰되, 띠별 ω는 실제 프로파일의 띠 평균을 정확히 계산해 넣었다(적합에 편향 없음, 주기당 5.3띠).
- β = α: +19.9 ± 5.5로 단일 주기(20.1 ± 4.4)와 같다 → 회전 항은 국소적이다(예측과 일치).
- β = 0: +16.8 ± 5.1로 단일 주기(29.8 ± 3.4)보다 2.1σ 작다. 그러나 판정량인 차이(β = 0 − β = α)는 −3.1 ± 7.5로
  단일 주기 +9.7 ± 5.6보다 12.8 ± 9.3(1.4σ) 작아 **2σ 기준에 못 미친다.** FL 항이 짧은 파장에서 약해지는 경향은 보이지만 비국소 응답으로 확정하지 않는다.

  세 D의 비가 오차 안에서 같으므로 D 의존은 비율의 B 민감도로 설명된다. 다만 D = 0.2, 0.4의 측정 오차가 커서 판별력은 약하다.
