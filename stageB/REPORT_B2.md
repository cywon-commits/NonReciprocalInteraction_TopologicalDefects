## 1. 구현

- **P10:** u = 0, Gilbert 식의 D_t = ∂_t + Ω ẑ×, Ω(y) = ω(y)/2, ω(y)는 P5의 프로파일 −(2πu₀/L)cos(2πy/L), u₀ = 0.04, β = α = 0.1.
  LL 꼴로는 정확히 Ṡ = [LL 항]/(1 + α²) − Ω ẑ×S (감쇠 짝 없음; 유도는 `skynuc/model.py:_rhs_site` 주석). P10b는 Ω → −Ω.
- **부호 확인:** 이완된 스커미온 둘레에 강체 회전 흐름 u = Ωẑ×r(ω = 2Ω)를 두면 중앙차분 (u·∇)S와 +Ωẑ×S의 상대 차이가 5.0 %
  (반대 부호는 197 %). 5 %는 V3와 같은 중앙차분 인자다. 따라서 ω 규약(ω = ∂_x u_y − ∂_y u_x, u = u_x(y)x̂이면 ω = −∂_y u_x)이 단계 B와 같다.
- **P14:** u_x = u₁ sin ky + u₃ sin 3ky, u₁ = 0.04, u₃ = −u₁/3, 띠 평균 ω와 ψ = ∫u_x dy = −(u₁/k)(cos ky − cos 3ky / 9).
  두 변수 푸아송 GLM ln Γ_b = a + a_ω ω_b + a_ψ ψ_b. 띠 사이 ω–ψ 상관 0.79, 매개변수 상관 −0.79. 점마다 t = 16000 (핵생성 ≈ 4000).
- **P11:** B/D² = 4/3 고정 (D = 0.3, B = 0.12와 같음): D = 0.2 → B = 0.0533 (R = 4.0a), D = 0.4 → B = 0.2133 (R ≈ 1.9a).
  두 경우 모두 E_sk − E_FM ≈ 6 J로 기준과 같다. 무구동 시험에서 Γ₀ = 3.0×10⁻⁶ (D = 0.2), 4.1×10⁻⁶ (D = 0.4) (기준 3.8×10⁻⁶).
  D = 0.2는 비율이 낮아 t = 11000으로 늘렸다.
- **P13:** L = 32는 같은 총넓이를 위해 복제본 64개. L = 128 반복은 새 씨드.
- 모든 점에서 핵생성 ≥ 1943 (P15 B = 0.14 제외), 원시 플래그 8–11 %, 복제본당 스커미온 0.5–0.7 (L = 128: 2.8, 넓이 4배).

## 3. 예측과 다른 점

1. **P10b 크기:** −7 ± 9.5로 예측 −20보다 작다(1.4σ). P10과 P10b의 대칭 부분 (P10 + P10b)/2 = +7.7 ± 7.1은 0과 1σ 안이다.
   현재 통계로는 "Ω에 홀"과 모순되지 않는다.
2. **P11:** s_rot이 D와 함께 커지지 않는다(D = 0.4에서 +7.8 ± 8.8). B/D²를 고정했으므로 D = 0.4의 스커미온은 R ≈ 1.9a로 작아 격자 효과가 크다.
   DMI 필요성 자체(D → 0에서 s_rot → 0)는 이 범위에서 시험되지 않았다.
3. **P14의 β 차이:** 단일 정현 전단(P1 대 P5)에서는 β = 0이 β = α보다 ≈ 10 크다(30 대 20). P14에서는 β = 0이 +14.2 ± 5.4, β = α가 +20.3 ± 5.4로 오히려 작다.
   k(β − α)/α 항이 3ky 성분(파장 L/3 ≈ 21a)에서 약해진다면 설명되지만(예: u_eff 결합이 스커미온 수송 길이에 걸친 비국소 응답일 때), 이 해석은 검증하지 않았다.
4. **s_col:** 대부분 음수(−10 내외)이고 β와 거의 무관하다. P10에서 −13 ± 9, P10b에서 +10 ± 8로 회전 부호를 따른다.

## 4. 제안

- P10/P10b 통계를 2배로 늘리면 반대칭성(크기 같음)을 2σ → 3σ로 확인할 수 있다(코어 4개 기준 약 1.5시간).
- D → 0 시험: D를 줄이면 스커미온이 커져 비율이 달라지므로, D = 0.2, 0.15에서 B를 맞춘 P10을 직접 돌리는 편이 깨끗하다.
- P14의 β 차이: 단일 정현 전단에서 파장을 L/3로 줄인 계산(L = 64, 주기 3개)으로 k 항의 파장 의존을 직접 본다.
